#បញ្ជី

វីដេអូត្រូវបានដាក់ជាក្រុមតាមការដំណើរការ (រាល់ពេលចុច Process) ថ្មីបំផុតនៅខាងលើ ហើយ Not started នៅលើគេ។ ជួរនីមួយៗបង្ហាញវីដេអូ ស្លាកសម្រាប់ជំហាននីមួយៗ (រួច កំពុងធ្វើ បរាជ័យ ឬរំលង) និងស្ថានភាពរបស់វា៖ Waiting, ជំហានដែលកំពុងធ្វើ, Failed at …, Stopped at …, Ready to post ឬ Posted។

  • តម្រង៖ All, Running, Waiting, Failed, Ready to post និង Posted ព្រមទាំង Search videos។
  • Retry failed ដំណើរការវីដេអូដែលបរាជ័យទាំងអស់ម្តងទៀត ចាប់ពីជំហានដែលបរាជ័យ។
  • Clear finished ដកវីដេអូដែលរួច និងបរាជ័យចេញពីបញ្ជី។ គម្រោង និងវីដេអូនាំចេញនៅដដែល។

  • Retry from … (វីដេអូបរាជ័យ) បន្តពីជំហានដែលបរាជ័យ។ ជំហានមុនៗនៅតែរួចដដែល។

  • ⋯ មាន Show … export in Finder, Step details និង Remove from the list។

បញ្ជីត្រូវបានរក្សាទុក ដូច្នេះក្រោយបើកឡើងវិញ អ្នកឃើញកន្លែងដែលអ្វីៗបានឈប់។ វារក្សាការដំណើរការ 20 ចុងក្រោយ។

#ព័ត៌មានលម្អិតនៃជំហាន

ចុចលើជួរមួយ (ឬ See why ក្បែរកំហុស) ដើម្បីបើកព័ត៌មានលម្អិតនៅខាងស្តាំ៖ គ្រប់ជំហានពីលើចុះក្រោម ជាមួយពេលដែលវាដំណើរការ រយៈពេល និងអ្វីដែលវាបាននិយាយ (ចំនួនឃ្លាដែលបកប្រែ ឯកសារនាំចេញ ឬកំហុស)។

  • ជំហានដែលបរាជ័យមាន Retry from here និង Fix by hand។
  • ជំហានដែលរួចមាន Run again from … ដែលដំណើរការជំហាននោះ និងគ្រប់ជំហានបន្ទាប់ម្តងទៀត។ មានប្រយោជន៍ក្រោយពេលអ្នកប្តូរការកំណត់ ដូចជារចនាប័ទ្ម។
  • Exports បង្ហាញឯកសារនាំចេញ នីមួយៗមាន Show in Finder។

#Ready to post

វីដេអូដែលរួចរាល់រង់ចាំនៅ Ready to post។ កាតនីមួយៗបង្ហាញវីដេអូ ឯកសារនាំចេញ និងជួរសម្រាប់ YouTube, Facebook និង TikTok៖

  1. គូសធីកកន្លែងដែលវាត្រូវទៅ។ គណនីដែលបានភ្ជាប់ត្រូវបានគូសធីករួចជាស្រេច។
  2. ជ្រើសទម្រង់ សម្រាប់វេទិកានីមួយៗ៖ 16:9 ឬ 9:16។ YouTube ចាប់ផ្តើមនៅ 16:9, Facebook និង TikTok នៅ 9:16។ បើទម្រង់ណាមួយមិនទាន់នាំចេញ Kroma នាំចេញវាពេលអ្នកបង្ហោះ។
  3. បើក Post text ដើម្បីអាន និងកែចំណងជើង អត្ថបទ និង hashtag សម្រាប់វេទិកានីមួយៗ។
  4. ចុច Post លើកាត ឬគូសធីកកាតច្រើន ហើយចុច Post selected នៅខាងលើ។

YouTube visibility (Public, Unlisted ឬ Private) និង TikTok (Post now ឬ To drafts) នៅខាងលើ អនុវត្តចំពោះអ្វីៗទាំងអស់ដែលអ្នកបង្ហោះពីទីនេះ។ វេទិកានីមួយៗទទួលឯកសារតាមទម្រង់របស់វា។ Facebook ឡើងជា Reel ពេលវីដេអូរបស់វាជា 9:16 ហើយវែងមិនលើស 90 វិនាទី។

ក្រោយបង្ហោះ កាតបង្ហាញលទ្ធផលនៃវេទិកានីមួយៗ ហើយវីដេអូផ្លាស់ទៅ Posted។ Post again បង្ហោះវាម្តងទៀត ហើយ Clear posted ដកវីដេអូដែលបង្ហោះរួចចេញពីបញ្ជី។

ការបង្ហោះត្រូវការរៀបចំ Upload-Post តែម្តង៖ មើល ការបង្ហោះ។ សូមបង្ហោះតែវីដេអូដែលអ្នកមានសិទ្ធិប្រើប៉ុណ្ណោះ។

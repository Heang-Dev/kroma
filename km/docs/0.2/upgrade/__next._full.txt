<p>គម្រោង និងការកំណត់របស់អ្នកនៅដដែល។ គម្រោងដែលរក្សាទុកដោយកំណែថ្មីជាង អាចប្រើអ្វីដែលកំណែចាស់មិនស្គាល់ (ឧទាហរណ៍ កំណែចាស់បង្ហាញអក្សររត់ដោយគ្មានចលនា) ដូច្នេះសូមរក្សាច្បាប់ចម្លងនៃអ្វីដែលសំខាន់ មុនពេលត្រឡប់ក្រោយ។ អានឯកសារណែនាំរបស់កំណែចាស់ ដោយប្រើម៉ឺនុយកំណែនៅខាងលើរបារចំហៀង ហើយមើលអ្វីដែលបានផ្លាស់ប្តូរក្នុង<a href="/kroma/km/docs/0.2/release-notes/">កំណត់ចំណាំកំណែ</a>។</p>

<h2 id="ផ្លាស់ទៅកុំព្យូទ័រថ្មី"><a class="anchor" href="#ផ្លាស់ទៅកុំព្យូទ័រថ្មី" aria-hidden="true">#</a>ផ្លាស់ទៅកុំព្យូទ័រថ្មី</h2><ol>
<li>ដំឡើង Kroma លើកុំព្យូទ័រថ្មី (<a href="/kroma/km/docs/0.2/installation/">ការដំឡើង</a>) ហើយលើ Mac ដំឡើងឧបករណ៍ម្តងទៀត (<code>brew install ffmpeg yt-dlp</code>)។</li>
<li>បន្ថែម API key របស់អ្នកម្តងទៀតក្នុង <a href="/kroma/km/docs/0.2/settings/">Settings</a>។ key ត្រូវបានអ៊ិនគ្រីបដោយ keychain របស់កុំព្យូទ័រចាស់ ដូច្នេះមិនអាចចម្លងទៅបានទេ។</li>
<li>ដំឡើងម៉ាស៊ីនសំឡេងម្តងទៀតក្នុង <strong>Settings → Voice Engine</strong> បើអ្នកប្រើវា។</li>
<li>ដើម្បីរក្សាសំឡេងក្លូន ចម្លងថត <code>voices</code> ពីថតបណ្ណាល័យ Kroma Studio ចាស់ ទៅក្នុងថតថ្មី នៅកន្លែងដដែល។ ចម្លង <code>stories</code> ផងដែរសម្រាប់រឿងរបស់អ្នក និង <code>my-styles.json</code> (ក្នុងថតការកំណត់) សម្រាប់រចនាប័ទ្មរបស់អ្នក។</li>
<li>ដើម្បីយកគម្រោងទៅ សូមធ្វើតាម <a href="/kroma/km/docs/0.2/projects-and-files/#ផ្លាស់គម្រោងទៅកុំព្យូទ័រផ្សេង">ផ្លាស់គម្រោងទៅកុំព្យូទ័រផ្សេង</a>។ ឯកសារគម្រោងគ្រាន់តែចង្អុលទៅវីដេអូ និងបន្ទាត់សំឡេងរបស់វា ដូច្នេះវាត្រូវតែចម្លងទៅកន្លែងដដែលផងដែរ។ សម្រាប់រឿងភាគ ចម្លងថតរបស់វាក្នុង <code>projects</code> ដែលមាន <code>kroma-glossary.json</code> របស់វា។</li>
</ol>

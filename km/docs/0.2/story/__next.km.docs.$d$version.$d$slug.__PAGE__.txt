<h2 id="តួអង្គ"><a class="anchor" href="#តួអង្គ" aria-hidden="true">#</a>តួអង្គ</h2><p>តួអង្គនីមួយៗក្នុងស្គ្រីបបង្ហាញក្នុង <strong>Cast</strong> ភ្លាមៗពេលអ្នកចាប់ផ្តើមឃ្លារបស់គេ។ សម្រាប់តួនីមួយៗ៖</p>
<ul>
<li><strong>Voice</strong>៖ សំឡេងលំនាំដើមរបស់ម៉ាស៊ីន សំឡេងមួយក្នុង <strong>Your voices</strong> (សំឡេងចម្លង) ឬសំឡេងស្រាប់ ដាក់ជាក្រុមដូចក្នុង <a href="/kroma/km/docs/0.2/voice-library/">បណ្ណាល័យសំឡេង</a>។ Kroma ជ្រើសសំឡេងសមរម្យតាមឈ្មោះ៖ &quot;Narrator&quot; ទទួលបាន <em>Narrator (deep male)</em>, &quot;grandpa&quot; ឬ &quot;លោកតា&quot; ទទួលបាន <em>Storyteller (warm grandfather)</em>, &quot;girl&quot; ឬ &quot;ស្រី&quot; ទទួលបាន <em>Young girl</em> ជាដើម។ អ្នកប្តូរបានគ្រប់ពេល។ សំឡេងភ្លាមៗ (instant) មិនមាននៅទីនេះទេ ព្រោះរឿងត្រូវបានអានដោយម៉ាស៊ីន។</li>
<li><strong>Style</strong> (ជម្រើស)៖ របៀបដែលតួនេះនិយាយគ្រប់ឃ្លា ដូចជា &quot;calm&quot;។ របៀបដែលសរសេរក្នុងឃ្លាផ្ទាល់ ដូចជា <code>Sokha (whisper):</code> ប្រើសម្រាប់តែឃ្លានោះ។</li>
</ul>
<p>ដើម្បីបន្ថែមតួអង្គ វាយឈ្មោះនៅក្រោមបញ្ជីតួ ហើយចុច <strong>Add</strong>។ បន្ទាត់ថ្មីមួយចាប់ផ្តើមសម្រាប់គេក្នុងស្គ្រីប ហើយទស្សន៍ទ្រនិចរង់ចាំអ្នកវាយ។</p>
<p>តួអង្គរហូតដល់ <strong>6</strong> នាក់ទទួលបានសំឡេងផ្ទាល់ខ្លួន។ បើលើសនេះ ពួកគេអានដោយសំឡេង Narrator ហើយ Kroma ព្រមានអ្នក។</p>
<h2 id="បង្កើតរឿង"><a class="anchor" href="#បង្កើតរឿង" aria-hidden="true">#</a>បង្កើតរឿង</h2><p>ដាក់ចំណងជើងឱ្យរឿង (ឬទុក <strong>Untitled story</strong>) ហើយចុច <strong>Generate story</strong>។ របារវឌ្ឍនភាពបង្ហាញពេលម៉ាស៊ីនកំពុងធ្វើការ។ រឿងវែងអាចចំណាយពេលយូរ ជាពិសេសលើកុំព្យូទ័រដែលគ្មានកាតក្រាហ្វិកលឿន។ ពេលរួច អ្នកទទួលបានការជូនដំណឹង <strong>Story ready: …</strong> ហើយរឿងបើកក្នុង <strong>Listen</strong>។</p>
<h2 id="ស្តាប់-និងកែឃ្លាមួយ"><a class="anchor" href="#ស្តាប់-និងកែឃ្លាមួយ" aria-hidden="true">#</a>ស្តាប់ និងកែឃ្លាមួយ</h2><p><strong>Listen</strong> បង្ហាញចំណងជើង ចំនួនឃ្លា រយៈពេល និងពេលដែលវាត្រូវបានបង្កើត រួចកម្មវិធីចាក់។ គ្រប់ឃ្លាត្រូវបានរាយនៅខាងក្រោម ជាមួយអ្នកនិយាយ។</p>

  • នៅក្រោមវីដេអូ៖ ពេលវេលាបច្ចុប្បន្ន Back 5 seconds (⇧←), Play / Pause, Forward 5 seconds (⇧→) និងរយៈពេលសរុប។
  • វត្ថុ (អក្សរ រូបភាព ប្រអប់ព្រិល) អាចអូសនៅលើផ្ទាំងមើលជាមុន ដើម្បីផ្លាស់ទី ហើយប្តូរទំហំពីជ្រុងរបស់វា។

#បញ្ជី Subtitles

ផ្ទាំងនៅខាងស្តាំ បង្ហាញឃ្លាអក្សររត់ទាំងអស់។ ក្បាលផ្ទាំងបង្ហាញចំនួនឃ្លា និងចំនួនដែលបានបកប្រែ ឧទាហរណ៍ "120 lines · 118 in Khmer"។

ឃ្លានីមួយៗបង្ហាញ៖

  • ពេលវេលា របស់វា (ចាប់ផ្តើម → បញ្ចប់)។ ចុចលើពេលវេលា ដើម្បីលោតវីដេអូទៅកន្លែងនោះ។
  • ឃ្លាដើម ពណ៌ប្រផេះ បើមាន។
  • ឃ្លាបកប្រែ នៅខាងក្រោម។ ចុចលើវា ហើយវាយដើម្បីកែ។ ឃ្លាដែលមិនទាន់បកប្រែ សរសេរថា "Not translated yet"។
  • ពេលអ្នកកំណត់តួអង្គរួច មានស្លាកបង្ហាញ អ្នកណានិយាយឃ្លានេះ។ ចុចវា ដើម្បីជ្រើសតួអង្គផ្សេង Default voice ឬ New character…។
  • រូបធុងសំរាម ពេលដាក់ម៉ៅស៍លើ ដើម្បី Delete line។

ប៊ូតុងនៅខាងលើស្តាំ៖ Import an .srt file, Find and replace និង Add a line at the playhead (ឃ្លាថ្មី ២ វិនាទី នៅពេលបច្ចុប្បន្ន)។ ខាងក្រោមនោះ Find in subtitles ច្រោះបញ្ជីឱ្យនៅសល់តែឃ្លាដែលមានពាក្យរបស់អ្នក ជាភាសាណាមួយក៏បាន។

ពេលវីដេអូកំពុងចាក់ បញ្ជីរំកិលដើម្បីរក្សាឃ្លាបច្ចុប្បន្នឱ្យនៅក្នុងទិដ្ឋភាព។ មើល អក្សររត់។

#Timeline

Timeline នៅខាងក្រោមមានពីរបន្ទាត់៖ Subtitles នៅខាងលើ និង Video នៅខាងក្រោម ជាមួយបន្ទាត់វាស់ពេលវេលានៅពីលើ។

  • ចុច ឬអូសលើបន្ទាត់វាស់ ឬលើបន្ទាត់ណាមួយ ដើម្បីផ្លាស់ទី playhead (បន្ទាត់ដែលសម្គាល់ពេលបច្ចុប្បន្ន)។
  • ឃ្លីបវីដេអូ៖ អូសឃ្លីប ដើម្បីប្តូរលំដាប់ ឬអូសគែមរបស់វា ដើម្បីកាត់។
  • ប្លុកអក្សររត់៖ អូសដើម្បីផ្លាស់ទីឃ្លា ឬអូសគែមរបស់វា ដើម្បីប្តូរពេលចាប់ផ្តើម និងបញ្ចប់។
  • របារឧបករណ៍៖ Split at the playhead (S), Delete the selection (Delete ឬ Backspace) បន្ទាប់មកនៅខាងស្តាំ Zoom out គ្រាប់រំកិលពង្រីក Zoom in និង Fit the whole video។
  • សង្កត់ ⌘ (ឬ Ctrl) ហើយរំកិល ឬច្បិចលើ trackpad ដើម្បីពង្រីកជុំវិញទស្សន៍ទ្រនិច។
  • ចុច ← ឬ → ដើម្បីទៅមួយស៊ុម Esc ដើម្បីដកការជ្រើស។

ពេលអ្វីមួយត្រូវបានជ្រើស របារឧបករណ៍ប្រាប់អ្វីដែលអ្នកអាចធ្វើជាមួយវា ឧទាហរណ៍ "Subtitle selected · drag to move, edges to retime"។

#របារស្ថានភាព

របារស្តើងនៅខាងក្រោមបំផុតនៃគ្រប់ទំព័រ បង្ហាញការងារទាំងមូល តាំងពីដើមដល់ចប់៖

Video → Subtitles → Khmer → Characters → Voices → Style → Export

  • ជំហាននីមួយៗមានលេខ ឬសញ្ញាធីកពណ៌បៃតង ពេលធ្វើរួច។
  • ចុចលើជំហាន ដើម្បីបើកផ្ទាំងរបស់វា (ពីទំព័រផ្សេង វានាំអ្នកត្រឡប់ទៅកម្មវិធីកែ)។ Export បើកជម្រើសទំហំនាំចេញ។
  • Characters, Style និង Voices (ពេលសំឡេងបញ្ចូលបិទ) មានសម្គាល់ថា optional។ អក្សររត់តែម្យ៉ាងក៏ជាវីដេអូពេញលេញដែរ។
  • ជំហាន Khmer បង្ហាញភាសាដែលអ្នកបកប្រែទៅ ដូច្នេះវាសរសេរថា Thai បើអ្នកបកប្រែទៅភាសាថៃ។
  • នៅខាងស្តាំ Next តែងតែចង្អុលទៅជំហានដំបូងដែលនៅមិនទាន់ធ្វើ ឧទាហរណ៍ Next: Get the subtitles ឬ Next: Export the video។ ពេលធ្វើរួចទាំងអស់ វាសរសេរថា All done។

នៅចុងខាងស្តាំ៖

  • Batch · 3/5 ពេល batch កំពុងដំណើរការ។ ចុចវាដើម្បីបើក Batch។
  • ម៉ាស៊ីនសំឡេង៖ Voice engine on, Voice engine off · Start, Voice engine not installed, installing… ឬ starting…។ ចុចវាដើម្បីបើកម៉ាស៊ីន ឬបើកការកំណត់របស់វា។ មើល ម៉ាស៊ីនសំឡេង។
  • Check for updates ឬវឌ្ឍនភាពនៃការធ្វើបច្ចុប្បន្នភាព ឬ Restart to update ក្រោយពេលអ្នកលាក់ប្រអប់ធ្វើបច្ចុប្បន្នភាព។ មើល ការធ្វើបច្ចុប្បន្នភាព។

#ការប្តូរទំហំផ្ទាំង

ផ្នែកបីអាចប្តូរទំហំបាន ដោយអូសគែមរបស់វា៖ ផ្ទាំងឧបករណ៍ (គែមស្តាំ) បញ្ជី Subtitles (គែមឆ្វេង) និង timeline (គែមខាងលើ)។

ផ្ទាំង តូចបំផុត លំនាំដើម ធំបំផុត
ផ្ទាំងឧបករណ៍ 300 px ប្រហែលមួយភាគបួននៃបង្អួច (360–440 px) 600 px
បញ្ជី Subtitles 300 px ប្រហែលមួយភាគបួននៃបង្អួច (360–440 px) 680 px
Timeline 140 px 210 px 520 px

ចុចពីរដងលើគែម ដើម្បីដាក់ផ្ទាំងនោះមកទំហំលំនាំដើមវិញ។ អ្នកក៏អាចចុចលើគែម ហើយប្រើគ្រាប់ចុចព្រួញបានដែរ។ Kroma ចងចាំទំហំរបស់អ្នកនៅលើកុំព្យូទ័រនេះ។

#ភ្លឺ ងងឹត និងទំហំផ្ទាំង

  • Theme៖ នៅក្នុង Settings → Appearance ជ្រើស Dark (លំនាំដើម) Light ឬ System (តាមការកំណត់កុំព្យូទ័ររបស់អ្នក)។
  • Interface size៖ ធ្វើឱ្យអ្វីៗធំ ឬតូចជាងមុន ដូចការពង្រីកទំព័រវេប។ ជ្រើសពី 70% ដល់ 140% នៅក្នុង Settings → Appearance (90% ជាលំនាំដើម) ឬចុច ⌘+ / ⌘− និង ⌘0 សម្រាប់ 100%។ នៅលើ Windows និង Linux ប្រើ Ctrl ជំនួស ⌘។ ធាតុទាំងនេះក៏មាននៅក្នុងម៉ឺនុយ View ដែរ។

#បង្អួចច្រើនជាងមួយ

អ្នកអាចធ្វើការលើគម្រោងពីរក្បែរគ្នា។ បើក New Window ដោយ៖

  • File → New Window ឬ ⇧⌘N (Ctrl+Shift+N លើ Windows និង Linux)។
  • ចុចខាងស្តាំលើ Kroma នៅ Dock (Mac) ឬ taskbar (Windows) ហើយជ្រើស New Window។

បង្អួចនីមួយៗមានគម្រោង និងការរក្សាទុកស្វ័យប្រវត្តិផ្ទាល់ខ្លួន។ គម្រោងរបស់បង្អួចទីមួយ បើកមកវិញពេលអ្នកបើក Kroma លើកក្រោយ។ បើអ្នកបិទបង្អួចបន្ថែមដែលគម្រោងមិនទាន់រក្សាទុកក្នុងឯកសារ Kroma សួរ Close this window? ជាមុនសិន៖ ជ្រើស Cancel ហើយចុច ⌘S ដើម្បីរក្សាការងាររបស់អ្នក។

ការបើក Kroma ម្តងទៀតពេលវាកំពុងដំណើរការ មិនបើកច្បាប់ទីពីរទេ។ វានាំបង្អួចដែលកំពុងបើកមកខាងមុខ។

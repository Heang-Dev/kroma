ម៉ាស៊ីនសំឡេង

Kroma មានសំឡេងពីរប្រភេទ ដែលឮខុសគ្នាខ្លាំង៖

  • សំឡេងរហ័ស (Instant) គឺជាសំឡេងឥតគិតថ្លៃរបស់ Microsoft។ វាប្រើបានភ្លាម មិនត្រូវការ key ឬការរៀបចំអ្វីទេ។ អ្នកត្រូវការតែអ៊ីនធឺណិតប៉ុណ្ណោះ។
  • សំឡេងរចនា (Designed) និង សំឡេងចម្លង (Cloned) គឺជាសំឡេងខ្មែរធម្មជាតិ មានអារម្មណ៍។ ពួកវាមកពី ម៉ាស៊ីនសំឡេងរបស់ Kroma ដែលមានស្រាប់ក្នុង Kroma។ អ្នកមិនត្រូវការកម្មវិធីផ្សេងទេ។

ទំព័រនេះពន្យល់ពីរបៀបដំឡើង និងដំណើរការម៉ាស៊ីន។ បើអ្នកប្រើតែសំឡេងរហ័ស អ្នកអាចរំលងទំព័រនេះបាន។

#សំឡេងរហ័ស៖ មិនបាច់រៀបចំអ្វីទេ

សំឡេងរហ័ស គឺជាសំឡេងអានឮដូចគ្នានឹងដែល Microsoft Edge ប្រើ។ Kroma សុំសេវាឥតគិតថ្លៃរបស់ Microsoft ឱ្យនិយាយឃ្លានីមួយៗ ហើយរក្សាទុកលទ្ធផល។

  • មានសំឡេងពីរ (ស្រី និងប្រុស) សម្រាប់ភាសានីមួយៗ ក្នុងចំណោម ៧ ភាសារបស់ Kroma។ មើល បណ្ណាល័យសំឡេង។
  • Kroma និយាយបានរហូតដល់ ៦ ឃ្លាក្នុងពេលតែមួយ ដូច្នេះវីដេអូទាំងមូលប្រើពេលតែប៉ុន្មានវិនាទី។
  • សេវាឥតគិតថ្លៃនេះ ពេលខ្លះដាច់ពាក់កណ្តាលឃ្លា។ Kroma ភ្ជាប់ឡើងវិញ ហើយសាកម្តងទៀត រហូតដល់ ៤ ដងទៀត ដោយរង់ចាំយូរជាងមុនបន្តិចរាល់ដង។
  • បើគ្មានឃ្លាណាមួយដំណើរការសោះ អ្នកនឹងឃើញ "The voice service didn't answer"។ សូមពិនិត្យអ៊ីនធឺណិត ហើយសាកម្តងទៀត។

#ម៉ាស៊ីននេះធ្វើអ្វី

ម៉ាស៊ីនផ្តល់ឱ្យ Kroma នូវ៖

  • សំឡេងរចនា ៣៦ (អ្នកនិទានរឿង អ្នកអានព័ត៌មាន ស្តេច កុមារ…)
  • សំឡេងចម្លង ដែលបង្កើតពីការថតខ្លីមួយ។ មើល ការចម្លងសំឡេង និង
  • ស្ទូឌីយោរឿង ដែលអានស្គ្រីបទាំងមូល ដោយមានសំឡេងសម្រាប់តួអង្គនីមួយៗ។

ពេលអ្នកដាក់សំឡេងដោយសំឡេងរបស់ម៉ាស៊ីន Kroma ផ្ញើឃ្លាទាំងអស់សម្រាប់សំឡេងនោះជាការងារតែមួយ ដូច្នេះសំឡេងនៅដដែលពីឃ្លាមួយទៅឃ្លាមួយ។ បន្ទាប់មក វាកាត់លទ្ធផលជាឃ្លីបមួយសម្រាប់អក្សររត់នីមួយៗ ដោយប្រើពេលវេលារបស់ម៉ាស៊ីនផ្ទាល់។ ឃ្លីបនីមួយៗត្រូវបានរក្សាទុក ដូច្នេះលើកក្រោយ មានតែឃ្លាថ្មី ឬឃ្លាដែលបានកែប៉ុណ្ណោះ ដែលត្រូវផ្ញើទៅម៉ាស៊ីន។

ម៉ាស៊ីនមិនរក្សាទុកសំឡេងរបស់អ្នកទេ។ ពួកវានៅលើកុំព្យូទ័ររបស់អ្នក ហើយ Kroma ផ្ញើការថតទៅជាមួយការងារនីមួយៗ។

ម៉ាស៊ីនដំណើរការលឿនជាងបើមានកាតក្រាហ្វិក (GPU)។ អ្នកជ្រើសកន្លែងដែលវាដំណើរការក្នុង Settings → Voice Engine៖ លើកុំព្យូទ័រនេះ ឬលើ GPU ឥតគិតថ្លៃរបស់ Google Colab។

#ដំឡើងម៉ាស៊ីន

បើក Settings (⌘,) → Voice Engine។ ស្ថានភាពនៅខាងលើបង្ហាញមួយក្នុងចំណោម៖ "Not installed", "Installing…", "Starting…", "On" ឬ "Off"។ នៅជាប់វាមានប៊ូតុងសម្រាប់ស្ថានភាពនោះ។

បើវាថា "Not installed" ចុច Install voice engine។ នេះជាជំហានតែម្តង។ Kroma រៀបចំ Python និងកញ្ចប់របស់ម៉ាស៊ីននៅក្នុងថតផ្ទាល់ខ្លួនរបស់វា។ វាប្រើពេលប៉ុន្មាននាទី និងទំហំប្រហែល 2 GB។ បើកុំព្យូទ័ររបស់អ្នកគ្មានកម្មវិធីដំឡើង Python Kroma ទាញយកមួយតូច (uv) ដោយខ្លួនឯង។

ស្ថានភាព ប៊ូតុង អ្វីដែលវាធ្វើ
Not installed Install voice engine ដំឡើងម៉ាស៊ីន តែម្តង។

On Stop បញ្ឈប់វា។ ម៉ាស៊ីនដែល Kroma បានចាប់ផ្តើម នឹងឈប់ពេល Kroma បិទ។
ណាមួយ Check ពិនិត្យម្តងទៀត។
ម៉ាស៊ីនថ្មីជាង Update បង្ហាញជាមួយ "This version of Kroma has a newer engine" បន្ទាប់ពីអាប់ដេត Kroma។

បើម៉ាស៊ីនចាប់ផ្តើមមិនបាន Show the log លេចឡើង ដើម្បីឱ្យអ្នកឃើញមូលហេតុ។

#កន្លែងដែលវាដំណើរការ

កុងតាក់ក្រោម Where it runs ជ្រើស This computer ឬ Google Colab (free GPU)។

#កុំព្យូទ័រនេះ

  • បើក Start the engine with Kroma ដើម្បីចាប់ផ្តើមម៉ាស៊ីនរាល់ពេល Kroma បើក។
  • លើ Mac វាប្រើ GPU របស់ Apple។ ល្អសម្រាប់ឃ្លាខ្លី ប៉ុន្តែយឺតជាងសម្រាប់រឿងវែង។ Colab លឿនជាងច្រើនដង។
  • ការចាប់ផ្តើមលើកដំបូង ទាញយកម៉ូដែលសំឡេង (ប្រហែល 5 GB)។ បន្ទាប់មក វាចាប់ផ្តើមលឿន។
  • ក្រោម Installed engine ប៊ូតុង Remove ដោះលែងទំហំប្រហែល 2 GB។ អ្នកអាចដំឡើងវាម្តងទៀតគ្រប់ពេល។

អាសយដ្ឋានម៉ាស៊ីនគឺ http://127.0.0.1:7861 ដែលជាលំនាំដើមរួចហើយ។ អ្នកមិនត្រូវការ token ទេ។

#Google Colab (GPU ឥតគិតថ្លៃ)

Google Colab អនុញ្ញាតឱ្យអ្នកដំណើរការកម្មវិធីលើកុំព្យូទ័ររបស់ Google ក្នុងកម្មវិធីរុករក រួមទាំង GPU ឥតគិតថ្លៃផង។ មានបីជំហាន៖

  1. ចុច Open in Colab។ វាបើក notebook របស់ Kroma (engine/colab/Kroma_Voice_Engine.ipynb ក្នុង repository សាធារណៈ Heang-Dev/KROMA.STUDIO លើ GitHub)។ អ្នកមិនត្រូវការគណនី GitHub ឬ token ទេ។
  2. ក្នុង Colab ជ្រើស Runtime → Change runtime type → T4 GPU រួចជ្រើស Runtime → Run all។ ការដំណើរការលើកដំបូងប្រើពេលប្រហែល ៥ នាទី។ ក្រឡាចុងក្រោយបង្ហាញ Address (មើលទៅដូចជា https://….trycloudflare.com) និង Token (ពាក្យសម្ងាត់សម្រាប់ម៉ាស៊ីន)។
  3. ក្នុង Kroma បិទភ្ជាប់អាសយដ្ឋានទៅក្នុង Engine address និង token ទៅក្នុង Token។

សូមទុកផ្ទាំង Colab ឱ្យបើក ពេលអ្នកប្រើ Kroma។

#ពិនិត្យស្ថានភាព

Kroma ពិនិត្យម៉ាស៊ីន រាល់ពេលអ្នកប្តូរការកំណត់។ ចុច Check ដើម្បីពិនិត្យម្តងទៀត។ របារស្ថានភាពនៅខាងក្រោមគ្រប់ទំព័រ ក៏បង្ហាញ "● Voice engine on", "off" ឬ "not installed" ដែរ។ ចុចលើវាដើម្បីចាប់ផ្តើមម៉ាស៊ីន (ពេលវាបានដំឡើងហើយ និងបិទ) ឬដើម្បីបើក Settings → Voice Engine។ របារខាងលើនៃ Story studio បង្ហាញស្ថានភាពដូចគ្នា ជាមួយប៊ូតុង Start។

ពេលវាដំណើរការ អ្នកឃើញ "On" និងអ្វីមួយដូចជា៖

  • GPU មានន័យថាវាកំពុងដំណើរការលើកាតក្រាហ្វិក (លឿន) ឧទាហរណ៍លើ Colab។
  • this computer (slower) មានន័យថាវាកំពុងដំណើរការលើ Mac របស់អ្នក (យឺតជាង GPU)។
  • ចំនួនសំឡេងរចនា គឺជាបញ្ជីផ្ទាល់របស់ម៉ាស៊ីន។
  • "job(s) running" លេចឡើង ពេលម៉ាស៊ីនកំពុងរវល់ធ្វើការ។

ពេលវាមិនដំណើរការ អ្នកឃើញមូលហេតុ។ មូលហេតុញឹកញាប់៖

សារ ត្រូវធ្វើអ្វី
"Can't reach the voice engine at
. Start it in Settings → Voice Engine (or keep its Colab notebook running)."
 ម៉ាស៊ីនមិនកំពុងដំណើរការ ឬអាសយដ្ឋានខុស។ ចាប់ផ្តើមវា រួចពិនិត្យអាសយដ្ឋាន។
"The voice engine refused the token. Copy the token from the engine (Colab prints it) into Settings → Voice Engine." បិទភ្ជាប់ token ម្តងទៀត ឱ្យដូចបេះបិទនឹងអ្វីដែល Colab បង្ហាញ។
"Voice engine error …" ម៉ាស៊ីនមានបញ្ហាជាមួយការងារ។ សារប្រាប់ថាជាអ្វី។

#ពេលម៉ាស៊ីនមិនអាចប្រើបាន

Kroma នៅតែដំណើរការ។ មានតែសំឡេងរបស់ម៉ាស៊ីនប៉ុណ្ណោះដែលត្រូវរង់ចាំ៖

  • ក្នុងផ្ទាំង Voice ពេលអ្នកជ្រើស Designed ឬ Cloned ប្រអប់មួយបង្ហាញសារណាមួយ៖
    • "These voices need the voice engine. Install it once in Settings (about 2 GB)." ចុច Install the engine។
    • "The voice engine is off." ចុច Start engine។
    • "Kroma can't reach your Colab voice engine. …" ចុច Set up the engine។
  • ពេលម៉ាស៊ីនបើក ផ្ទាំងនេះបង្ហាញ "The voice engine (this computer, slower / GPU): natural, expressive voices…"។
  • Make voice-over ប្រែជាពណ៌ប្រផេះ ពេលសំឡេងដែលបានជ្រើសជាសំឡេងរបស់ម៉ាស៊ីន។
  • សំឡេងរចនានៅតែបង្ហាញក្នុងបញ្ជី (Kroma មានបញ្ជីផ្ទាល់ខ្លួនមួយច្បាប់) ដូច្នេះអ្នកអាចជ្រើសសំឡេងសម្រាប់តួអង្គទុកជាមុនបាន។
  • សំឡេងដែលមានសំឡេងគំរូរក្សាទុករួចហើយ នៅតែចាក់ដោយ ▶ បាន។
  • ប៊ូតុង Make a sample បង្ហាញ Start the engine to make a sample ហើយ Clone voice ប្រែជាពណ៌ប្រផេះ។
  • សំឡេងរហ័សនៅតែដំណើរការដូចធម្មតា។

ពេលការងាររបស់ម៉ាស៊ីនកំពុងដំណើរការ វឌ្ឍនភាពបង្ហាញសាររបស់ម៉ាស៊ីនផ្ទាល់ ឧទាហរណ៍ "Voice engine: …" ជាមួយពេលវេលាប៉ាន់ស្មាន ពេលម៉ាស៊ីនផ្តល់ឱ្យ។

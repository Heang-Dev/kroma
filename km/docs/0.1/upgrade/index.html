ការណែនាំអំពីការដំឡើងកំណែ

របៀបផ្លាស់ទៅកំណែ Kroma ថ្មីជាង អ្វីដែលនៅដដែល និងរបៀបត្រឡប់ទៅកំណែចាស់វិញ។

#ក្នុងស៊េរី 0.1៖ មិនចាំបាច់ធ្វើអ្វីទេ

ចាប់ពី 0.1.1 ទៅ គ្រប់កំណែ 0.1.x ធ្វើបច្ចុប្បន្នភាពដោយខ្លួនឯង៖

  1. Kroma ពិនិត្យរកកំណែថ្មីពេលវាចាប់ផ្តើម និងរៀងរាល់ ៤ ម៉ោងម្តង។
  2. វាទាញយកកំណែថ្មីនៅពីក្រោយ។ ប្រអប់មួយនៅខាងស្តាំខាងក្រោមបង្ហាញដំណើរការ។
  3. ពេលប្រអប់នោះបង្ហាញ Restart to update ចុចវាពេលអ្នករួចរាល់។ Kroma បើកឡើងវិញជាមួយកំណែថ្មី ហើយគម្រោងរបស់អ្នកបើកមកវិញ។

ចុច Later ដើម្បីលាក់ប្រអប់ នោះ Restart to update នៅតែមាននៅរបារស្ថានភាពខាងក្រោម។ អ្នកក៏អាចពិនិត្យដោយដៃក្នុង Settings → About → Check now បានដែរ។ ព័ត៌មានលម្អិតសម្រាប់ប្រព័ន្ធនីមួយៗ មាននៅ ការធ្វើបច្ចុប្បន្នភាព។

បើអ្នកបានបិទ Update automatically Kroma គ្រាន់តែប្រាប់អ្នកថាមានកំណែថ្មី។ ចុច Download លើប្រអប់នោះ ពេលអ្នកចង់បានវា។

#ពី 0.1.0 ទៅ 0.1.1 ឬថ្មីជាងនេះ

0.1.0 មិនអាចធ្វើបច្ចុប្បន្នភាពដោយខ្លួនឯងបានទេ។ ធ្វើបែបនេះម្តង៖

  1. ទាញយកកំណែចុងក្រោយពីទំព័រទាញយក។
  2. ដំឡើងវាពីលើកំណែចាស់ ដូចដែលអ្នកបានដំឡើង Kroma (ការដំឡើង)។ លើ Mac អូសវាទៅក្នុង Applications ហើយជ្រើសជំនួសកម្មវិធីចាស់។
  3. បើកវា។ ចាប់ពីពេលនេះទៅ ការធ្វើបច្ចុប្បន្នភាពមកដោយខ្លួនឯង។

#អ្វីដែលនៅដដែល

ការធ្វើបច្ចុប្បន្នភាពគ្រាន់តែជំនួសកម្មវិធីប៉ុណ្ណោះ។ អ្វីៗដែលអ្នកបានបង្កើតនៅដដែល ព្រោះវាស្ថិតនៅក្រៅកម្មវិធី (ទីតាំងឯកសារ)៖

អ្វី នៅដដែល? ទីតាំង
គម្រោងរបស់អ្នក (ឯកសារ .kroma) បាទ/ចាស កន្លែងណាដែលអ្នកបានរក្សាទុក
គម្រោងដែលអ្នកកំពុងបើក បាទ/ចាស វាបើកមកវិញ autosave ក្នុងថតការកំណត់របស់ Kroma
ការកំណត់ និង API key បាទ/ចាស settings.json ក្នុងថតការកំណត់របស់ Kroma
សំឡេងក្លូន និងគំរូសំឡេង បាទ/ចាស voices ក្នុងថតបណ្ណាល័យ Kroma Studio
បន្ទាត់សំឡេង ការទាញយក ការនាំចេញ បាទ/ចាស ថតបណ្ណាល័យ Kroma Studio
ទំហំផ្ទាំង បាទ/ចាស កន្លែងផ្ទុកផ្ទាល់ខ្លួនរបស់ Kroma ក្នុងថតការកំណត់

គម្រោងដែលបង្កើតក្នុងកំណែ 0.1.x ណាមួយ បើកបានក្នុងគ្រប់កំណែ 0.1.x ក្រោយៗទៀត។

#ដំឡើងកំណែចាស់

បើកំណែថ្មីបង្កបញ្ហាដល់អ្នក អ្នកអាចត្រឡប់ក្រោយវិញបាន៖

  1. បិទ Settings → About → Update automatically ដើម្បីកុំឱ្យ Kroma ធ្វើបច្ចុប្បន្នភាពម្តងទៀតភ្លាមៗ។
  2. បើក GitHub Releases ហើយរកកំណែដែលអ្នកចង់បាន។
  3. នៅក្រោម Assets ទាញយកឯកសារសម្រាប់ប្រព័ន្ធរបស់អ្នក៖
ប្រព័ន្ធ ឯកសារ
macOS ឯកសារ .dmg
Windows Kroma-Studio-Setup-<version>.exe
Linux Kroma-Studio-<version>-<arch>.AppImage ឬកញ្ចប់ .deb
  1. ដំឡើងវាពីលើកំណែបច្ចុប្បន្ន ដូចក្នុង ការដំឡើង។

គម្រោង និងការកំណត់របស់អ្នកនៅដដែល។ គម្រោងដែលរក្សាទុកដោយកំណែថ្មីជាង អាចប្រើអ្វីដែលកំណែចាស់មិនស្គាល់ ដូច្នេះសូមរក្សាច្បាប់ចម្លងនៃអ្វីដែលសំខាន់ មុនពេលត្រឡប់ក្រោយ។ អានឯកសារណែនាំរបស់កំណែចាស់ ដោយប្រើម៉ឺនុយកំណែនៅខាងលើរបារចំហៀង ហើយមើលអ្វីដែលបានផ្លាស់ប្តូរក្នុងកំណត់ចំណាំកំណែ។

សូមរាយការណ៍បញ្ហាផងដែរ ដើម្បីឱ្យវាអាចត្រូវបានជួសជុល។

#ផ្លាស់ទៅកុំព្យូទ័រថ្មី

  1. ដំឡើង Kroma លើកុំព្យូទ័រថ្មី (ការដំឡើង) ហើយលើ Mac ដំឡើងឧបករណ៍ម្តងទៀត (brew install ffmpeg yt-dlp)។
  2. បន្ថែម API key របស់អ្នកម្តងទៀតក្នុង Settings។ key ត្រូវបានអ៊ិនគ្រីបដោយ keychain របស់កុំព្យូទ័រចាស់ ដូច្នេះមិនអាចចម្លងទៅបានទេ។
  3. ដើម្បីរក្សាសំឡេងក្លូន ចម្លងថត voices ពីថតបណ្ណាល័យ Kroma Studio ចាស់ ទៅក្នុងថតថ្មី នៅកន្លែងដដែល។
  4. ដើម្បីយកគម្រោងទៅ សូមធ្វើតាម ផ្លាស់គម្រោងទៅកុំព្យូទ័រផ្សេង។ ឯកសារគម្រោងគ្រាន់តែចង្អុលទៅវីដេអូ និងបន្ទាត់សំឡេងរបស់វា ដូច្នេះវាត្រូវតែចម្លងទៅកន្លែងដដែលផងដែរ។

ការកំណត់ផ្សេងទៀតរបស់អ្នក (អ្នកបកប្រែ ថត រូបរាង ជាដើម) នៅក្នុង settings.json។ អ្នកអាចចម្លងឯកសារនោះទៅក្នុងថតការកំណត់របស់កុំព្យូទ័រថ្មី ពេល Kroma បិទ។ key នៅក្នុងវានឹងមិនដំណើរការទេ ដូច្នេះសូមបន្ថែមវាម្តងទៀត។

<li>ពេល <strong>Remove the original voices</strong> បិទ សំឡេងដើមចាក់នៅកម្រិត <strong>Original sound</strong> (15% ជាលំនាំដើម) នៅក្រោមសំឡេងថ្មី។</li>
</ul>
<p>បើការលុបសំឡេងបរាជ័យ Kroma ប្រាប់អ្នកថា <em>&quot;The original voices are still in&quot;</em> ហើយសំឡេងដើមចាក់តិចៗនៅក្រោមសំឡេងថ្មី។ សាកម្តងទៀតពី <strong>Voice → Mix</strong>។</p>

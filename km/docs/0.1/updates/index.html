ការធ្វើបច្ចុប្បន្នភាព

Kroma ធ្វើបច្ចុប្បន្នភាពដោយខ្លួនឯង។ កំណែថ្មីទាញយកនៅពីក្រោយ ពេលអ្នកកំពុងធ្វើការ ហើយអ្នកជ្រើសពេលបើកឡើងវិញ។ គម្រោងរបស់អ្នកត្រូវបានរក្សាទុក ហើយបើកមកវិញក្រោយពេលបើកឡើងវិញ។

#របៀបដែលវាដំណើរការ

  1. Kroma ពិនិត្យរកកំណែថ្មី។ ការពិនិត្យលើកដំបូងកើតឡើងប៉ុន្មានវិនាទីក្រោយ Kroma ចាប់ផ្តើម បន្ទាប់មករៀងរាល់ ៤ ម៉ោងម្តង ពេលវាកំពុងបើក។ កំណែថ្មីមកពី GitHub Releases។
  2. វាទាញយកនៅពីក្រោយ។ ប្រអប់មួយលេចឡើងនៅជ្រុងខាងក្រោមស្តាំ៖ Downloading Kroma 0.1.4, "It downloads in the background. Keep working." ជាមួយរបារដំណើរការ និងភាគរយ។
  3. វារួចរាល់។ ប្រអប់ប្តូរទៅជា Kroma 0.1.4 is ready, "Restart to finish updating. Your project is saved and opens again." វាមានប៊ូតុងពីរ៖
    • Restart to update៖ Kroma បិទ ដំឡើងកំណែថ្មី ហើយបើកឡើងវិញជាមួយគម្រោងរបស់អ្នក។
    • Later៖ លាក់ប្រអប់។ អ្នកអាចបន្តធ្វើការបានយូរតាមចិត្ត។

បើ Kroma ជាកំណែចុងក្រោយស្រាប់ គ្មានអ្វីលេចឡើងទេ។

#ក្រោយពេលចុច Later

ប្រអប់នៅតែលាក់សម្រាប់កំណែនោះ ប៉ុន្តែការធ្វើបច្ចុប្បន្នភាពមិនបាត់ទេ។ ពាក្យ Restart to update តូចពណ៌បៃតង នៅតែមាននៅលើរបារជំហានខាងក្រោមបង្អួច ផ្នែកខាងស្តាំ ក្បែរប៊ូតុង Next។ ចុចវា ដើម្បីបង្ហាញប្រអប់មកវិញ។

បើអ្នកលាក់ប្រអប់ពេលវាកំពុងទាញយក របារជំហានបង្ហាញ Updating ជាមួយភាគរយជំនួសវិញ។

អ្នកក៏អាចលាក់ប្រអប់ដោយចុច × នៅជ្រុងខាងលើស្តាំរបស់វា។ វាដូចគ្នានឹង Later ដែរ។

#របៀបដំឡើងលើប្រព័ន្ធនីមួយៗ

សំឡេង

ការចម្លងសំឡេង

ការចម្លងសំឡេង បង្កើតសំឡេងថ្មីមួយពីការថតខ្លីរបស់មនុស្សម្នាក់។ ពេលបង្កើតរួច អ្នកអាចប្រើវាជាសំឡេងរបស់គម្រោង ឬផ្តល់វាឱ្យតួអង្គណាក៏បាន។

ការចម្លងត្រូវការឱ្យ ម៉ាស៊ីនសំឡេង កំពុងដំណើរការ។ សំឡេងចម្លងធ្វើឡើងសម្រាប់ភាសាខ្មែរ។

#ការយល់ព្រមមកមុនគេ

ចម្លងតែ សំឡេងរបស់អ្នកផ្ទាល់ ឬសំឡេងរបស់អ្នកដែលបានអនុញ្ញាតឱ្យអ្នកប៉ុណ្ណោះ។

មុនពេល Kroma ចម្លងអ្វីមួយ អ្នកត្រូវធីកប្រអប់នេះ៖

This is my voice, or I have the speaker's permission to clone it. I won't use it to pretend to be someone or to mislead people.

(នេះជាសំឡេងរបស់ខ្ញុំ ឬខ្ញុំមានការអនុញ្ញាតពីម្ចាស់សំឡេងឱ្យចម្លងវា។ ខ្ញុំនឹងមិនប្រើវាដើម្បីក្លែងខ្លួនជាអ្នកដទៃ ឬបោកបញ្ឆោតមនុស្សទេ។)

ប៊ូតុង Clone voice នៅពណ៌ប្រផេះ រហូតដល់អ្នកធីកប្រអប់នេះ។

កុំប្រើសំឡេងចម្លងដើម្បីក្លែងខ្លួនជាអ្នកដទៃ រួមទាំងអ្នកចម្រៀង តារាសម្តែង និងបុគ្គលល្បីៗផ្សេងទៀត។ កុំចម្លងសំឡេងពីវីដេអូមួយ គ្រាន់តែដោយសារអ្នកបានទាញយកវា។

#ចាប់ផ្តើមពីណា

អ្នកអាចបើកផ្ទាំងចម្លងពីកន្លែងពីរ៖

  • Voices (ម៉ឺនុយខាងឆ្វេង) → Clone voice នៅខាងស្តាំខាងលើ។ មើល បណ្ណាល័យសំឡេង។
  • ផ្ទាំង Voice → Voice type: Cloned → Clone a voice នៅខាងក្រោមបញ្ជី។ បើអ្នកមិនទាន់មានសំឡេងចម្លង ការជ្រើស Cloned បើកផ្ទាំងនេះភ្លាម។

ទាំងពីរបើកផ្ទាំងតែមួយ ឈ្មោះ Clone a voice។ វាមាន៖

  1. ប្រអប់ Name (ឧទាហរណ៍ "My voice")
  2. ជម្រើសរវាង Record now និង Use a file
  3. ប្រអប់យល់ព្រម
  4. ប៊ូតុង Cancel និង Clone voice

បើអ្នកទុកឈ្មោះទទេ សំឡេងនោះនឹងមានឈ្មោះ "My voice"។

#ថតក្នុងកម្មវិធី

Record now ជាវិធីងាយបំផុត ហើយជាធម្មតាល្អបំផុតផង។

  1. អានអត្ថបទខ្មែរក្នុងប្រអប់ពណ៌ប្រផេះ។ វាសរសេរថា "Read this aloud, clearly and at an easy pace" (អានឱ្យឮ ច្បាស់ និងមិនប្រញាប់)។ បើអ្នកចង់បានអត្ថបទផ្សេង ចុច Another text (មានបីអត្ថបទឱ្យជ្រើស)។
  2. ចុចប៊ូតុងមីក្រូហ្វូនពណ៌ក្រហមធំ ហើយចាប់ផ្តើមអាន។
  3. របារកម្រើកពេលអ្នកនិយាយ ដូច្នេះអ្នកអាចឃើញថាមីក្រូហ្វូនឮអ្នក។ ការរាប់បង្ហាញវិនាទី ឧទាហរណ៍ "8 / 20 s"។
  4. ពេលអានអត្ថបទចប់ ចុចប៊ូតុងបញ្ឈប់ (ការ៉េពណ៌ក្រហម)។
  5. ស្តាប់ឡើងវិញ ជាមួយកម្មវិធីចាក់។ ចុច Record again បើវាមិនច្បាស់។
  6. វាយឈ្មោះ ធីកប្រអប់យល់ព្រម ហើយចុច Clone voice។

#រយៈពេលប៉ុន្មាន

  • យ៉ាងតិច ៥ វិនាទី។ បើអ្នកបញ្ឈប់មុននេះ អ្នកនឹងឃើញ "That was only 3.2 s. Read the whole text: at least 5 seconds."
  • យ៉ាងច្រើន ២០ វិនាទី។ ការថតឈប់ដោយខ្លួនឯងនៅ ២០ វិនាទី។
  • អត្ថបទនីមួយៗ ប្រើពេលប្រហែល ១៥ វិនាទី ដើម្បីអានដោយមិនប្រញាប់។

ពេលកំពុងថត ការណែនាំបង្ហាញ keep reading ក្នុង ៥ វិនាទីដំបូង បន្ទាប់មក press stop when you finish the text។

#ហេតុអ្វីការអានអត្ថបទជួយ

ដោយសារអ្នកអានអត្ថបទដែល Kroma ដឹងស្រាប់ ម៉ាស៊ីនមិនបាច់ស្វែងយល់ថាអ្នកនិយាយអ្វីទេ។ វារំលងជំហាននោះ ហើយរក្សាទុកអត្ថបទដូចដែលអ្នកអានបេះបិទ ដូច្នេះគ្មានហានិភ័យដែលវាស្តាប់ពាក្យខុសទេ។

#គន្លឹះសម្រាប់ការថតល្អ

  • ថតក្នុងបន្ទប់ស្ងាត់ គ្មានតន្ត្រី ទូរទស្សន៍ ឬសំឡេងកង្ហារ។
  • ជៀសវាងបន្ទប់ដែលមានសំឡេងបន្លឺ (echo)។
  • និយាយដោយសំឡេងធម្មតារបស់អ្នក មិនប្រញាប់។ សំឡេងនឹងឮដូចរបៀបដែលអ្នកអាន។
  • ពេលស្តាប់ឡើងវិញ ពិនិត្យថាវាច្បាស់ គ្មានតន្ត្រី ឬសំឡេងបន្លឺ។ កម្មវិធីក៏រំលឹកអ្នកពីចំណុចនេះដែរ។
  • បន្ទាត់នៅក្រោមរបារ បង្ហាញមីក្រូហ្វូនដែលកំពុងប្រើ ("Microphone: …")។ បើវាខុស សូមប្តូរវាក្នុងការកំណត់សំឡេងរបស់កុំព្យូទ័រ។

#ការអនុញ្ញាតមីក្រូហ្វូន (Mac)

លើកដំបូង macOS សួរថា តើ Kroma អាចប្រើមីក្រូហ្វូនបានទេ។ ចុច Allow។

បើអ្នកធ្លាប់ឆ្លើយថាទេ អ្នកនឹងឃើញ "Kroma isn't allowed to use the microphone."។ ចុច Open Microphone settings បើក Kroma នៅក្រោម Privacy & Security → Microphone រួចសាកម្តងទៀត។

#ប្រើឯកសារ

ជ្រើស Use a file បើអ្នកមានការថតរួចហើយ។

  1. ចុច Choose an audio or video file…។
  2. ជ្រើសឯកសារមួយ។ Kroma ទទួល WAV, MP3, M4A, AAC, OGG, FLAC, MP4, MOV និង WebM។
  3. វាយឈ្មោះ ធីកប្រអប់យល់ព្រម ហើយចុច Clone voice។

ដើម្បីបានសំឡេងចម្លងល្អ ឯកសារគួរមាន៖

  • ការនិយាយ ៥ ដល់ ២០ វិនាទី
  • មនុស្សតែម្នាក់ ប៉ុណ្ណោះ
  • និយាយ ច្បាស់ជាភាសាខ្មែរ
  • គ្មានតន្ត្រី និងសំឡេងរំខានតិចបំផុតតាមដែលអាចធ្វើបាន

ម៉ាស៊ីនសម្អាតការថត៖ វាកាត់ចុងក្បាល ធ្វើឱ្យកម្រិតសំឡេងស្មើ ហើយរក្សាទុកយ៉ាងច្រើន ២០ វិនាទី។ ជាមួយឯកសារ ម៉ាស៊ីនក៏សរសេរពាក្យដែលនិយាយចុះដែរ ព្រោះ Kroma មិនដឹងពាក្យទាំងនោះ។

#អ្វីកើតឡើងពេលចុច Clone voice

ប៊ូតុងប្តូរទៅជា Cloning… ហើយវឌ្ឍនភាពបង្ហាញសាររបស់ម៉ាស៊ីន។ ពេលរួចរាល់៖

  • សារមួយប្រាប់ ឧទាហរណ៍ "Voice "My voice" is ready."
  • សំឡេងថ្មីលេចឡើងក្រោម Your voices នៅលើទំព័រ Voices
  • បើអ្នកចាប់ផ្តើមពីផ្ទាំង Voice សំឡេងថ្មីក្លាយជាសំឡេងរបស់គម្រោង។

សំឡេងចម្លងត្រូវបានរក្សាទុកលើកុំព្យូទ័ររបស់អ្នក ក្នុងថត Kroma Studio/voices ក្នុងថត Movies។ ម៉ាស៊ីនមិនរក្សាទុកច្បាប់ចម្លងទេ។

#ការប្រើសំឡេងចម្លង

  • សម្រាប់គម្រោងទាំងមូល៖ ក្នុងផ្ទាំង Voice ជ្រើស Voice type: Cloned ហើយចុចលើសំឡេង។ វាបង្ហាញ "· in use"។ ឬនៅលើទំព័រ Voices ប្រើម៉ឺនុយ ⋯ របស់កាត → Use in this project។
  • សម្រាប់តួអង្គម្នាក់៖ ជ្រើសវាពីម៉ឺនុយសំឡេងរបស់តួអង្គ ក្រោម Your voices។ មើល តួអង្គ និងសំឡេង។

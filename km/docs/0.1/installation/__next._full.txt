<li>បើក <strong>Kroma Studio</strong> ពី Applications ឬ Launchpad។</li>

<p>សូមបើក Kroma ពី <strong>Applications</strong> ជានិច្ច កុំបើកពីក្នុង <code>.dmg</code>។ Kroma អាចធ្វើបច្ចុប្បន្នភាពខ្លួនឯងបាន លុះត្រាតែវាអាចជំនួសកម្មវិធីនៅកន្លែងដែលបានដំឡើង។</p>
<h3 id="kroma-studio-is-damaged-and-can-t-be-opened"><a class="anchor" href="#kroma-studio-is-damaged-and-can-t-be-opened" aria-hidden="true">#</a>«Kroma Studio is damaged and can&#39;t be opened»</h3><p>Kroma មិនទាន់មានហត្ថលេខាវិញ្ញាបនបត្ររបស់ Apple នៅឡើយទេ ដូច្នេះ macOS អាចប្រាប់ថាកម្មវិធីខូច ឬថាវាមិនអាចពិនិត្យរកមេរោគបាន។ តាមពិតកម្មវិធីគ្មានបញ្ហាទេ។ បើក <strong>Terminal</strong> (នៅក្នុង Applications → Utilities) បិទភ្ជាប់បន្ទាត់នេះ ហើយចុច Return៖</p>
<div class="code-block"><pre><code class="language-bash">xattr -cr &quot;/Applications/Kroma Studio.app&quot;</code></pre></div><p>វាដកសញ្ញា «ទាញយកពីអ៊ីនធឺណិត» ដែល macOS បានដាក់។ បន្ទាប់មកបើក Kroma ម្តងទៀត។ អ្នកត្រូវធ្វើតែម្តងប៉ុណ្ណោះ៖ ការធ្វើបច្ចុប្បន្នភាពដែល Kroma ដំឡើងដោយខ្លួនឯង ដកសញ្ញានេះឱ្យអ្នកស្រាប់។</p>

<h2 id="ការលុបកម្មវិធី"><a class="anchor" href="#ការលុបកម្មវិធី" aria-hidden="true">#</a>ការលុបកម្មវិធី</h2><ul>
<li><strong>Mac៖</strong> បិទ Kroma រួចអូស <strong>Kroma Studio</strong> ពី Applications ទៅធុងសំរាម។</li>
<li><strong>Windows៖</strong> បើក <strong>Settings → Apps → Installed apps</strong> រក <strong>Kroma Studio</strong> ហើយជ្រើស <strong>Uninstall</strong>។</li>
<li><strong>Linux AppImage៖</strong> លុបឯកសារ <code>.AppImage</code>។</li>
<li><strong>Linux .deb៖</strong> ដំណើរការ <code>sudo apt remove kroma-studio</code>។</li>
</ul>

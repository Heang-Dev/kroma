2b:T3119,<p>This page explains how Kroma keeps your work: the project file, autosave, extra windows, and where every file lives on your computer.</p>
<h2 id="the-project-file"><a class="anchor" href="#the-project-file" aria-hidden="true">#</a>The project file</h2><p>A Kroma project is a single file that ends in <strong>.kroma</strong>. It&#39;s a small text file (in a format called JSON) that holds your edit:</p>
<ul>
<li>the project name, the frame shape (16:9, 9:16 or 1:1) and how the video fits the frame</li>
<li>the list of videos you added, and where each one is on your computer</li>
<li>the clips on the timeline (which part of which video)</li>
<li>every subtitle line: its time, the original text, the translation and who says it</li>
<li>the subtitle style</li>
<li>your notes for the translator</li>
<li>the voice-over settings: voices, characters, speed, volumes, and where each spoken line is saved</li>
<li>objects on the video (blur boxes, images, text)</li>
<li>the translation language</li>
<li>the social posts written for the video, and where you posted it</li>
</ul>
<p><strong>What it doesn&#39;t hold:</strong> the videos, voice recordings and images themselves. The project only remembers <em>where</em> they are. Keep those files where they are, or the project can&#39;t find them. See <a href="#moving-a-project-to-another-computer">Moving a project to another computer</a>.</p>

<p>The <strong>Save project</strong>, <strong>Open project</strong> and <strong>New project</strong> buttons are at the top right of the window.</p>
<p>The save and open dialogs start in your <a href="#where-files-live">Kroma Studio library folder</a>, and the file name starts as the project name. When you add your first video, Kroma names the project after it. Click the name at the top to change it.</p>
<p>A small dot next to the project name means <strong>Unsaved changes</strong>: the project has changed since you last saved it to a file.</p>
<p>If you start a new project while the current one has never been saved to a file, Kroma asks first: <em>&quot;Start a new project? The current one isn&#39;t saved to a file (it stays in autosave until you start another).&quot;</em></p>
<h2 id="autosave-and-recovery"><a class="anchor" href="#autosave-and-recovery" aria-hidden="true">#</a>Autosave and recovery</h2><p>You don&#39;t need to save to keep your work safe. About a second and a half after every change, Kroma writes the open project to an autosave file.</p>
<p>When you open Kroma again, it reopens your last project and shows <strong>Reopened your last project.</strong> This also covers a crash, a power cut, or closing Kroma without saving. If the project was saved to a file, it reopens linked to that file. If not, it reopens with the unsaved dot, so you remember to save it.</p>
<p>Autosave keeps one project per window. Starting a new project replaces it. So for work you want to keep, use <strong>Save project</strong> too.</p>
<p>Undo history (100 steps) is not saved: after Kroma restarts, you can&#39;t undo changes from before.</p>
<h2 id="several-windows"><a class="anchor" href="#several-windows" aria-hidden="true">#</a>Several windows</h2><p>You can work on two projects at once, each in its own window.</p>
<ul>
<li><strong>File → New Window</strong> (⇧⌘N / Ctrl+Shift+N)</li>
<li>Mac: right-click Kroma in the Dock → <strong>New Window</strong></li>
<li>Windows: right-click Kroma on the taskbar → <strong>New Window</strong></li>
</ul>
<p>Each window has its own project and its own autosave slot:</p>
<div class="table-wrap"><table>
<thead>
<tr>
<th>Window</th>
<th>Autosave</th>
</tr>
</thead>
<tbody><tr>
<td>The first window</td>
<td><code>autosave.json</code>. Reopened when Kroma starts.</td>
</tr>
<tr>
<td>Each extra window</td>
<td><code>autosave-2.json</code>, <code>autosave-3.json</code> … Deleted when you close that window.</td>
</tr>
</tbody></table></div>
<p>Because an extra window&#39;s autosave goes away, Kroma asks before you close an extra window whose project isn&#39;t saved to a file: <strong>Close this window?</strong> Choose <strong>Cancel</strong>, save the project, then close it.</p>
<h2 id="only-one-kroma-at-a-time"><a class="anchor" href="#only-one-kroma-at-a-time" aria-hidden="true">#</a>Only one Kroma at a time</h2><p>Kroma runs only once. If you open it again while it&#39;s running (from the Dock, Start menu or a desktop shortcut), it brings the open window to the front instead of starting a second copy. This stops two copies writing the same autosave file. The taskbar&#39;s <strong>New Window</strong> opens a new window in the running Kroma.</p>
<p>On a Mac, closing every window leaves Kroma running. Click its Dock icon to open a window again. On Windows and Linux, closing the last window quits Kroma.</p>

<h2 id="your-keys-on-disk"><a class="anchor" href="#your-keys-on-disk" aria-hidden="true">#</a>Your keys on disk</h2><p>API keys are encrypted with your system&#39;s keychain before they&#39;re written to <code>settings.json</code>, and only work on the computer that saved them. On some Linux systems no keychain is available; there the keys are stored as plain text, so keep that file private.</p>
<h2 id="moving-a-project-to-another-computer"><a class="anchor" href="#moving-a-project-to-another-computer" aria-hidden="true">#</a>Moving a project to another computer</h2><p>The <code>.kroma</code> file only points to your files by their full location, for example <code>/Users/dara/Movies/Kroma Studio/downloads/…</code>. Kroma has no button to find moved files again. To move a project:</p>
<ol>
<li>Copy the <code>.kroma</code> file <strong>and</strong> the Kroma Studio library folder (with its <code>downloads</code>, <code>voice-cache</code>, <code>voices</code> and <code>cache</code> folders). Also copy any videos or images you added from other places.</li>
<li>Put them at <strong>exactly the same place</strong> on the new computer. This works best between two computers of the same kind (Mac to Mac, Windows to Windows) with the same user name.</li>
<li>Open the project with <strong>Open project</strong>.</li>
</ol>
<p>If the new computer&#39;s folders are different, the simplest way is to start a new project there and bring your subtitles with you:</p>
<ol>
<li>On the old computer, open the <strong>Post</strong> panel and, under <strong>Subtitle files</strong>, save the translated <code>.srt</code> (for Khmer, <strong>Khmer .srt</strong>).</li>
<li>On the new computer, add the video again, then use <strong>Import an .srt file</strong> above the subtitle list.</li>
</ol>
<p>An <code>.srt</code> file holds one language, so this brings back the translation, not the original lines, speakers or voice-over.</p>
<p>Keys don&#39;t move: they&#39;re locked to the computer that saved them. Add them again in <a href="/kroma/docs/0.1/settings/">Settings</a> on the new computer.</p>
<h2 id="clearing-space"><a class="anchor" href="#clearing-space" aria-hidden="true">#</a>Clearing space</h2><p>Kroma has no &quot;clear cache&quot; button, but you can delete these folders in the library folder yourself when Kroma is closed:</p>
<div class="table-wrap"><table>
<thead>
<tr>
<th>Folder</th>
<th>Safe to delete?</th>
</tr>
</thead>
<tbody><tr>
<td><code>cache/visuals</code></td>
<td>Yes, any time. Kroma makes the timeline pictures again when needed.</td>
</tr>
<tr>
<td><code>cache/separator-models</code></td>
<td>Yes. It&#39;s downloaded again the next time you remove voices.</td>
</tr>
<tr>
<td><code>downloads</code></td>
<td>Only for projects you&#39;ve finished. Projects that use a deleted video can&#39;t play or export it.</td>
</tr>
<tr>
<td><code>voice-cache</code></td>
<td>Only for projects you&#39;ve finished. Projects lose their spoken lines.</td>
</tr>
<tr>
<td><code>cache/separated</code></td>
<td>Only for projects you&#39;ve finished. Projects that removed the original voices lose that sound.</td>
</tr>
<tr>
<td><code>voices</code>, <code>recordings</code></td>
<td>No. These are your cloned voices. Delete a voice from the <strong>Voices</strong> page instead.</td>
</tr>
</tbody></table></div>
<p>Finished videos in <code>Exports</code> are yours to keep or delete as you like.</p>

Reference

Keyboard shortcuts

Every keyboard shortcut in Kroma Studio, in one place. On a Mac you use ⌘ (Command). On Windows and Linux you use Ctrl instead. Where a key is the same on every system, the table shows it once.

You can also see the editor shortcuts inside the app: open Settings → Shortcuts. On Windows and Linux, that list and the button tooltips already show Ctrl and Shift in place of the Mac symbols.

#Reading the keys

Symbol Key on a Mac Key on Windows / Linux
⌘ Command Ctrl
⇧ Shift Shift
⌥ Option Alt
⌫ Delete (backspace) Backspace

#Project

These work everywhere in the editor, even while you're typing in a text box.

Action macOS Windows / Linux
New project ⌘N Ctrl+N
Open project ⌘O Ctrl+O
Save project ⌘S Ctrl+S
Save project as a new file ⇧⌘S Ctrl+Shift+S
Open Settings ⌘, Ctrl+,

Save project writes to the project's file. The first time, it asks where to save. Save as a new file always asks, so you can keep a copy under a new name. See Projects and files.

#Editing

Action macOS Windows / Linux
Undo ⌘Z Ctrl+Z
Redo ⇧⌘Z Ctrl+Shift+Z
Split the clip at the playhead S S
Delete the selected clip, subtitle line or object ⌫ or Delete Backspace or Delete
Clear the selection Esc Esc

Undo remembers your last 100 changes. Opening or starting a project clears that history.

#Playback

Action macOS Windows / Linux
Play / pause Space Space
Step back one frame ← ←
Step forward one frame → →
Jump back 5 seconds ⇧← Shift+←
Jump forward 5 seconds ⇧→ Shift+→

Space only plays when there's a video on the timeline. One frame is 1/30 of a second.

#Timeline

Action macOS Windows / Linux
Zoom the timeline in or out around the pointer ⌘ + scroll, or pinch on the trackpad Ctrl + scroll
Move the playhead Click or drag in the timeline Click or drag in the timeline

The buttons above the timeline also zoom (Zoom in, Zoom out, Fit the whole video).

#Panels

You can resize the tools panel, the subtitle list and the timeline by dragging their edges. Each edge also works from the keyboard:

  1. Press Tab until the edge you want is highlighted.
  2. Use the arrow keys to make the panel bigger or smaller (16 pixels per press).
  3. Double-click an edge to put that panel back to its normal size.

#Interface size and window

Action macOS Windows / Linux
Bigger interface ⌘+ or ⌘= Ctrl+ + or Ctrl+=
Smaller interface ⌘− Ctrl+−
Interface at 100% ⌘0 Ctrl+0
New window ⇧⌘N Ctrl+Shift+N
Close the window ⌘W Ctrl+W
Minimize the window ⌘M Ctrl+M
Full screen on / off Control+⌘F F11
Quit Kroma ⌘Q File → Exit

The interface size changes every open window. It steps through 70%, 80%, 90%, 100%, 110%, 125% and 140%, and a short note shows the new size. You can also pick a size in Settings → Appearance.

#In Settings

Action macOS Windows / Linux
Search the settings ⌘F Ctrl+F
Open the first search result Enter Enter
Clear the search, or go back to the editor Esc Esc

Press Esc once to clear what you typed in the search box, and again to go back to the editor.

#Text boxes

While you type in a text box (a subtitle line, the project name, a post), the usual text keys work: copy, cut, paste, select all, and undo or redo inside that box. The editor's single-key shortcuts (Space, S, Delete, the arrows) are switched off while you type, so they never interrupt your writing. Click outside the box, or press Tab, to use them again.

Editor shortcuts also pause while a menu or a dialog is open, and while you're on the Settings or Voices page.

35:T160d,<p>How to move to a newer version of Kroma, what stays the same, and how to go back to an older one.</p>
<h2 id="within-0-1-nothing-to-do"><a class="anchor" href="#within-0-1-nothing-to-do" aria-hidden="true">#</a>Within 0.1: nothing to do</h2><p>From 0.1.1 on, every 0.1.x version updates itself:</p>
<ol>
<li>Kroma checks for a new version when it starts and every 4 hours.</li>
<li>It downloads the new version in the background. A card at the bottom right shows the progress.</li>
<li>When the card says <strong>Restart to update</strong>, click it when you&#39;re ready. Kroma restarts on the new version and your project opens again.</li>
</ol>
<p>Click <strong>Later</strong> to hide the card; <strong>Restart to update</strong> stays in the status bar at the bottom. You can also check by hand in <strong>Settings → About → Check now</strong>. Details for each system are on <a href="/kroma/docs/0.1/updates/">Updates</a>.</p>
<p>If you turned off <strong>Update automatically</strong>, Kroma only tells you a new version is out. Press <strong>Download</strong> on the card when you want it.</p>
<h2 id="from-0-1-0-to-0-1-1-or-later"><a class="anchor" href="#from-0-1-0-to-0-1-1-or-later" aria-hidden="true">#</a>From 0.1.0 to 0.1.1 or later</h2><p>0.1.0 can&#39;t update itself. Do this once:</p>
<ol>
<li>Download the latest version from the <a href="/kroma/#download">download page</a>.</li>
<li>Install it over the old one, the same way you installed Kroma (<a href="/kroma/docs/0.1/installation/">Installation</a>). On a Mac, drag it into <strong>Applications</strong> and choose to replace the old app.</li>
<li>Open it. From now on, updates come by themselves.</li>
</ol>
<h2 id="what-carries-over"><a class="anchor" href="#what-carries-over" aria-hidden="true">#</a>What carries over</h2><p>Updating only replaces the app. Everything you made is kept, because it lives outside the app (<a href="/kroma/docs/0.1/projects-and-files/#where-files-live">where files live</a>):</p>
<div class="table-wrap"><table>
<thead>
<tr>
<th>What</th>
<th>Kept?</th>
<th>Where it lives</th>
</tr>
</thead>
<tbody><tr>
<td>Your projects (<code>.kroma</code> files)</td>
<td>Yes</td>
<td>Wherever you saved them</td>
</tr>
<tr>
<td>The project you had open</td>
<td>Yes, it reopens</td>
<td>The autosave in Kroma&#39;s settings folder</td>
</tr>
<tr>
<td>Settings and API keys</td>
<td>Yes</td>
<td><code>settings.json</code> in Kroma&#39;s settings folder</td>
</tr>

</tr>

<td>Yes</td>

</tr>

<p>Projects made in any 0.1.x version open in every later 0.1.x version.</p>
<h2 id="installing-an-older-version"><a class="anchor" href="#installing-an-older-version" aria-hidden="true">#</a>Installing an older version</h2><p>If a new version gives you trouble, you can go back:</p>
<ol>
<li>Turn off <strong>Settings → About → Update automatically</strong>, so Kroma doesn&#39;t update again straight away.</li>
<li>Open <a href="https://github.com/Heang-Dev/kroma/releases" target="_blank" rel="noreferrer">GitHub Releases</a> and find the version you want.</li>
<li>Under <strong>Assets</strong>, download the file for your system:</li>
</ol>
<div class="table-wrap"><table>
<thead>
<tr>
<th>System</th>
<th>File</th>
</tr>
</thead>
<tbody><tr>
<td>macOS</td>
<td>the <code>.dmg</code></td>
</tr>
<tr>
<td>Windows</td>
<td><code>Kroma-Studio-Setup-&lt;version&gt;.exe</code></td>
</tr>
<tr>
<td>Linux</td>
<td><code>Kroma-Studio-&lt;version&gt;-&lt;arch&gt;.AppImage</code> or the <code>.deb</code></td>
</tr>
</tbody></table></div>
<ol start="4">
<li>Install it over the current one, as in <a href="/kroma/docs/0.1/installation/">Installation</a>.</li>
</ol>
<p>Your projects and settings stay. A project saved by a newer version may use things an older version doesn&#39;t know about, so keep a copy of anything important before going back. Read the older version&#39;s docs with the version menu at the top of the sidebar, and see what changed in the <a href="/kroma/docs/0.1/release-notes/">release notes</a>.</p>
<p>Please also <a href="/kroma/docs/0.1/troubleshooting/#reporting-a-problem">report the problem</a>, so it can be fixed.</p>
<h2 id="moving-to-a-new-computer"><a class="anchor" href="#moving-to-a-new-computer" aria-hidden="true">#</a>Moving to a new computer</h2><ol>
<li>Install Kroma on the new computer (<a href="/kroma/docs/0.1/installation/">Installation</a>), and on a Mac install the tools again (<code>brew install ffmpeg yt-dlp</code>).</li>
<li>Add your API keys again in <a href="/kroma/docs/0.1/settings/">Settings</a>. Keys are encrypted with the old computer&#39;s keychain, so they can&#39;t be copied over.</li>
<li>To keep cloned voices, copy the <code>voices</code> folder from the old Kroma Studio library folder into the new one, at the same place.</li>
<li>To bring a project, follow <a href="/kroma/docs/0.1/projects-and-files/#moving-a-project-to-another-computer">Moving a project to another computer</a>. The project file only points to its videos and voice lines, so they must be copied to the same places too.</li>
</ol>
<p>Your other settings (translator, folders, theme and so on) are in <code>settings.json</code>. You can copy that file into the new computer&#39;s settings folder while Kroma is closed; the keys in it won&#39;t work, so add them again.</p>

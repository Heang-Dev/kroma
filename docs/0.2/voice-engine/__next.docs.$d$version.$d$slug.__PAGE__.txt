33:T29ec,<p>Kroma has two kinds of voices that sound very different:</p>
<ul>
<li><strong>Instant voices</strong> are Microsoft&#39;s free voices. They work straight away, with no key and no setup. You only need an internet connection.</li>
<li><strong>Designed</strong> and <strong>cloned</strong> voices are natural, expressive Khmer voices. They come from <strong>Kroma&#39;s voice engine</strong>, which is built into Kroma. You don&#39;t need any other program.</li>
</ul>
<p>This page explains how to install and run the engine. If you only use instant voices, you can skip it.</p>
<h2 id="instant-voices-nothing-to-set-up"><a class="anchor" href="#instant-voices-nothing-to-set-up" aria-hidden="true">#</a>Instant voices: nothing to set up</h2><p>Instant voices are the same read-aloud voices Microsoft Edge uses. Kroma asks Microsoft&#39;s free service to speak each line and saves the result.</p>
<ul>
<li>There are two voices (female and male) for each of Kroma&#39;s 7 languages. See the <a href="/kroma/docs/0.2/voice-library/#instant-voices">Voice library</a>.</li>
<li>Kroma speaks up to 6 lines at once, so a whole video takes seconds.</li>
<li>The free service sometimes drops a line halfway. Kroma reconnects and tries again, up to 4 more times, waiting a little longer each time.</li>
<li>If no line works at all, you&#39;ll see &quot;The voice service didn&#39;t answer&quot;. Check your internet and try again.</li>
</ul>
<h2 id="what-the-engine-does"><a class="anchor" href="#what-the-engine-does" aria-hidden="true">#</a>What the engine does</h2><p>The engine gives Kroma:</p>
<ul>
<li>the <strong>36 designed voices</strong> (storyteller, news anchor, king, children…),</li>
<li><strong>cloned voices</strong>, made from a short recording. See <a href="/kroma/docs/0.2/voice-cloning/">Voice cloning</a>, and</li>
<li><strong><a href="/kroma/docs/0.2/story/">Story studio</a></strong>, which reads a whole script with a voice for each character.</li>
</ul>
<p>When you make a voice-over with an engine voice, Kroma sends all the lines for that voice as one job, so the voice stays the same from line to line. It then cuts the result into one clip per subtitle line, using the engine&#39;s own timings. Each clip is saved, so later only new or edited lines go to the engine.</p>
<p>The engine doesn&#39;t keep your voices. They&#39;re kept on your computer, and Kroma sends the recording along with each job.</p>
<p>The engine is quicker with a graphics card (GPU). You choose where it runs in <strong>Settings → Voice Engine</strong>: on this computer, or on a free Google Colab GPU.</p>
<h2 id="install-the-engine"><a class="anchor" href="#install-the-engine" aria-hidden="true">#</a>Install the engine</h2><p>Open <strong>Settings</strong> (⌘,) → <strong>Voice Engine</strong>. The status at the top shows one of: &quot;Not installed&quot;, &quot;Installing…&quot;, &quot;Starting…&quot;, &quot;On&quot; or &quot;Off&quot;. Next to it is the button for that state.</p>
<p>If it says &quot;Not installed&quot;, press <strong>Install voice engine</strong>. This is a one-time step. Kroma sets up Python and the engine&#39;s packages in its own folder. It takes a few minutes and about 2 GB. If your computer has no Python installer, Kroma downloads a small one (uv) by itself.</p>

<h2 id="where-it-runs"><a class="anchor" href="#where-it-runs" aria-hidden="true">#</a>Where it runs</h2><p>A switch under <strong>Where it runs</strong> chooses <strong>This computer</strong> or <strong>Google Colab (free GPU)</strong>.</p>
<h3 id="this-computer"><a class="anchor" href="#this-computer" aria-hidden="true">#</a>This computer</h3><ul>
<li>Turn on <strong>Start the engine with Kroma</strong> to start it each time Kroma opens.</li>
<li>On a Mac it uses the Apple GPU. That&#39;s fine for short lines but slower for long stories. Colab is several times faster.</li>
<li>The first start downloads the voice model (about 5 GB). After that it starts quickly.</li>
<li>Under <strong>Installed engine</strong>, <strong>Remove</strong> frees about 2 GB. You can install it again any time.</li>
</ul>
<p>The engine address is <code>http://127.0.0.1:7861</code>, which is already the default. You don&#39;t need a token.</p>
<h3 id="google-colab-free-gpu"><a class="anchor" href="#google-colab-free-gpu" aria-hidden="true">#</a>Google Colab (free GPU)</h3><p>Google Colab lets you run programs on Google&#39;s computers in your browser, including a free GPU. There are three steps:</p>
<ol>
<li>Press <strong>Open in Colab</strong>. It opens Kroma&#39;s notebook (<code>engine/colab/Kroma_Voice_Engine.ipynb</code> in the public Heang-Dev/KROMA.STUDIO repository on GitHub). You don&#39;t need a GitHub account or token.</li>
<li>In Colab choose <strong>Runtime → Change runtime type → T4 GPU</strong>, then <strong>Runtime → Run all</strong>. The first run takes about 5 minutes. The last cell prints an <strong>Address</strong> (it looks like <code>https://….trycloudflare.com</code>) and a <strong>Token</strong> (a password for the engine).</li>
<li>In Kroma, paste the address into <strong>Engine address</strong> and the token into <strong>Token</strong>.</li>
</ol>
<p>Keep the Colab tab open while you use Kroma.</p>

<h3 id="check-the-status"><a class="anchor" href="#check-the-status" aria-hidden="true">#</a>Check the status</h3><p>Kroma checks the engine each time you change a setting. Press <strong>Check</strong> to check again. The status bar at the bottom of every page also shows &quot;● Voice engine on&quot;, &quot;off&quot; or &quot;not installed&quot;. Click it to start the engine (when it&#39;s installed and off), or to open <strong>Settings → Voice Engine</strong>. The Story studio&#39;s top bar shows the same status with a <strong>Start</strong> button.</p>
<p>When it works, you see &quot;On&quot; and something like:</p>
<blockquote>
<p>Online · GPU · 36 designed voices · 1 job(s) running</p>
</blockquote>
<ul>
<li><strong>GPU</strong> means it&#39;s running on a graphics card (fast), for example on Colab.</li>
<li><strong>this computer (slower)</strong> means it&#39;s running on your Mac (slower than a GPU).</li>
<li>The number of designed voices is the engine&#39;s own list.</li>
<li>&quot;job(s) running&quot; appears when the engine is busy with work.</li>
</ul>

<h2 id="when-the-engine-isn-t-available"><a class="anchor" href="#when-the-engine-isn-t-available" aria-hidden="true">#</a>When the engine isn&#39;t available</h2><p>Kroma keeps working. Only the engine voices wait:</p>
<ul>
<li>In the <strong>Voice</strong> panel, when you choose <strong>Designed</strong> or <strong>Cloned</strong>, a box says one of:<ul>
<li>&quot;These voices need the voice engine. Install it once in Settings (about 2 GB).&quot; Press <strong>Install the engine</strong>.</li>
<li>&quot;The voice engine is off.&quot; Press <strong>Start engine</strong>.</li>
<li>&quot;Kroma can&#39;t reach your Colab voice engine. …&quot; Press <strong>Set up the engine</strong>.</li>
</ul>
</li>
<li>When the engine is on, the panel says &quot;The voice engine (this computer, slower / GPU): natural, expressive voices…&quot;.</li>
<li><strong>Make voice-over</strong> is greyed out while the chosen voice is an engine voice.</li>
<li>The designed voices are still listed (Kroma has its own copy of the list), so you can choose voices for characters ahead of time.</li>
<li>Voices that already have a saved sample can still be played with ▶.</li>
<li><strong>Make a sample</strong> buttons say <strong>Start the engine to make a sample</strong>, and <strong>Clone voice</strong> is greyed out.</li>
<li>Instant voices keep working as usual.</li>
</ul>
<p>While an engine job runs, the progress shows the engine&#39;s own messages, for example &quot;Voice engine: …&quot;, with a time estimate when the engine gives one.</p>
<h2 id="tips"><a class="anchor" href="#tips" aria-hidden="true">#</a>Tips</h2><ul>
<li>Engine voices are slower than instant ones. Check your timing with an instant voice first, then switch to a designed or cloned voice once the subtitles are final. Only changed lines are redone.</li>

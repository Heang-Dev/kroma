<h2 id="macos"><a class="anchor" href="#macos" aria-hidden="true">#</a>macOS</h2><h3 id="install"><a class="anchor" href="#install" aria-hidden="true">#</a>Install</h3><ol>
<li>Open the <code>.dmg</code> file you downloaded.</li>
<li>Drag <strong>Kroma Studio</strong> onto the <strong>Applications</strong> folder in the window that opens.</li>
<li>Eject the disk image (the drive icon called Kroma Studio in Finder&#39;s sidebar).</li>
<li>Open <strong>Kroma Studio</strong> from Applications or Launchpad.</li>
</ol>
<p>Always run Kroma from <strong>Applications</strong>, not from inside the <code>.dmg</code>. Kroma can only update itself when it can replace the app where it&#39;s installed.</p>
<h3 id="kroma-studio-is-damaged-and-can-t-be-opened"><a class="anchor" href="#kroma-studio-is-damaged-and-can-t-be-opened" aria-hidden="true">#</a>&quot;Kroma Studio is damaged and can&#39;t be opened&quot;</h3><p>Kroma isn&#39;t signed with an Apple certificate yet, so macOS may say the app is damaged, or that it can&#39;t check it for malicious software. The app is fine. Open <strong>Terminal</strong> (in Applications → Utilities), paste this line, and press Return:</p>
<div class="code-block"><pre><code class="language-bash">xattr -cr &quot;/Applications/Kroma Studio.app&quot;</code></pre></div><p>This removes the &quot;downloaded from the internet&quot; mark that macOS adds. Then open Kroma again. You only need to do this once: updates installed by Kroma itself clear the mark for you.</p>
<h3 id="install-ffmpeg-and-yt-dlp"><a class="anchor" href="#install-ffmpeg-and-yt-dlp" aria-hidden="true">#</a>Install FFmpeg and yt-dlp</h3><p>On a Mac, Kroma uses the video tools from <a href="https://brew.sh" target="_blank" rel="noreferrer">Homebrew</a>. Homebrew&#39;s FFmpeg can use the Mac&#39;s video chip, which makes exporting much faster. If you don&#39;t have Homebrew yet, install it from <a href="https://brew.sh" target="_blank" rel="noreferrer">brew.sh</a>, then run:</p>
<div class="code-block"><pre><code class="language-bash">brew install ffmpeg yt-dlp</code></pre></div><p>You don&#39;t need to tell Kroma where they are. It looks in Homebrew&#39;s folders (<code>/opt/homebrew/bin</code> and <code>/usr/local/bin</code>) on its own.</p>
<h2 id="windows"><a class="anchor" href="#windows" aria-hidden="true">#</a>Windows</h2><ol>
<li>Run <code>Kroma-Studio-Setup-&lt;version&gt;.exe</code>.</li>
<li>The installer isn&#39;t code-signed yet, so Windows may show <strong>&quot;Windows protected your PC&quot;</strong>. Click <strong>More info</strong>, then <strong>Run anyway</strong>.</li>
<li>Follow the steps. You can change the install folder if you like. Kroma installs for your Windows account only, so it doesn&#39;t need administrator rights.</li>
<li>Open <strong>Kroma Studio</strong> from the Start menu or the desktop shortcut.</li>
</ol>
<p>FFmpeg and yt-dlp come inside the app. There&#39;s nothing else to install.</p>
<h2 id="linux"><a class="anchor" href="#linux" aria-hidden="true">#</a>Linux</h2><h3 id="appimage"><a class="anchor" href="#appimage" aria-hidden="true">#</a>AppImage</h3><p>Make the file executable, then run it:</p>
<div class="code-block"><pre><code class="language-bash">chmod +x Kroma-Studio-*.AppImage
./Kroma-Studio-*.AppImage</code></pre></div><p>You can also right-click the file in your file manager, open <strong>Properties</strong>, and turn on &quot;Allow executing file as program&quot;.</p>
<p>If the AppImage doesn&#39;t start on a newer Ubuntu, install the FUSE library that AppImages need:</p>
<div class="code-block"><pre><code class="language-bash">sudo apt install libfuse2t64</code></pre></div><p>(On Ubuntu 22.04 and older the package is called <code>libfuse2</code>.)</p>
<h3 id="deb"><a class="anchor" href="#deb" aria-hidden="true">#</a>.deb</h3><p>Double-click the file to open it in your software installer, or run:</p>
<div class="code-block"><pre><code class="language-bash">sudo apt install ./Kroma-Studio-*.deb</code></pre></div><p>Both Linux versions include FFmpeg and yt-dlp.</p>

<h2 id="uninstalling"><a class="anchor" href="#uninstalling" aria-hidden="true">#</a>Uninstalling</h2><ul>
<li><strong>Mac:</strong> quit Kroma, then drag <strong>Kroma Studio</strong> from Applications to the Trash.</li>
<li><strong>Windows:</strong> open <strong>Settings → Apps → Installed apps</strong>, find <strong>Kroma Studio</strong>, and choose <strong>Uninstall</strong>.</li>
<li><strong>Linux AppImage:</strong> delete the <code>.AppImage</code> file.</li>
<li><strong>Linux .deb:</strong> run <code>sudo apt remove kroma-studio</code>.</li>
</ul>
<p>Uninstalling leaves your videos and projects alone. To remove everything, also delete the Library folder and the settings folder from the table above. Deleting the settings folder also deletes your saved API keys.</p>

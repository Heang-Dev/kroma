32:T4ba4,<p>A reference for every option in Settings: what it does and what it&#39;s set to when you first install Kroma.</p>
<h2 id="opening-settings"><a class="anchor" href="#opening-settings" aria-hidden="true">#</a>Opening Settings</h2><ul>
<li>Press ⌘, (Mac) or Ctrl+, (Windows / Linux), or</li>
<li>click <strong>Settings</strong> (the gear) at the bottom of the left menu.</li>
</ul>
<p>Settings fills the window. The pages are listed on the left in groups, with the version you&#39;re running at the bottom. <strong>Back to app</strong>, the <strong>×</strong> at the top right, or Esc takes you back to the editor.</p>
<p><strong>Changes save as you make them.</strong> There&#39;s no Save button, except for API keys.</p>
<p>To find an option fast, type in <strong>Search settings</strong> (⌘F / Ctrl+F). It matches page names and common words, like &quot;cookies&quot;, &quot;zoom&quot; or &quot;Groq&quot;. Press Enter to open the first match.</p>
<p>The very first time you open Kroma, Settings opens on <strong>Translation</strong> for you, so you can add a key. After that, Kroma opens where you work, also after a restart or an update.</p>
<h2 id="how-key-fields-work"><a class="anchor" href="#how-key-fields-work" aria-hidden="true">#</a>How key fields work</h2><p>Every API key field works the same way:</p>
<ul>
<li>Paste the key and press <strong>Save</strong>. The field then shows a <strong>Saved</strong> badge. Kroma never shows the key again.</li>
<li><strong>Replace</strong> lets you paste a new key. <strong>Cancel</strong> keeps the old one.</li>
<li><strong>Remove</strong> deletes the saved key.</li>
<li><strong>Get a key</strong> opens the page where that service gives you a key.</li>
<li><em>A key is saved, but this version of Kroma can&#39;t read it from the keychain.</em> means the key is still stored, but this copy of Kroma isn&#39;t allowed to read it (this can happen on a Mac after an update). Paste it again, or reopen Kroma and choose <strong>Always Allow</strong> when the Mac asks. The stored key is never replaced with an empty one.</li>
</ul>
<p>Keys are encrypted with your system&#39;s keychain and only sent to their own service. See <a href="/kroma/docs/0.2/projects-and-files/#your-keys-on-disk">Projects and files</a>.</p>

<p>Kroma posts to YouTube, Facebook and TikTok through Upload-Post (upload-post.com). See <a href="/kroma/docs/0.2/posting/">Posting</a>.</p>
<div class="table-wrap"><table>
<thead>
<tr>
<th>Option</th>
<th>What it does</th>
</tr>
</thead>
<tbody><tr>
<td><strong>API key</strong></td>
<td>Your Upload-Post key, from app.upload-post.com → API Keys.</td>
</tr>
<tr>
<td><strong>Account</strong></td>
<td>Your Upload-Post email and plan. <strong>Check</strong> tests the key again.</td>
</tr>
<tr>
<td><strong>Profile</strong></td>
<td>Only shown if you have more than one Upload-Post profile. Each profile has its own accounts.</td>
</tr>
<tr>
<td><strong>YouTube</strong>, <strong>Facebook</strong>, <strong>TikTok</strong></td>
<td>Which account is connected, <strong>Not connected</strong>, or &quot;sign-in expired: press Connect&quot;.</td>
</tr>
<tr>
<td><strong>Facebook Page</strong></td>

</tr>
<tr>

<td>Opens a secure Upload-Post page in your browser. Sign in to each platform and allow access, then come back: the list updates by itself.</td>

<p>TikTok needs Upload-Post&#39;s Basic plan. YouTube and Facebook work on the free plan (10 posts a month).</p>
<p>Before you add a key, <strong>Getting started</strong> shows the three steps: make a free account (<strong>Open</strong>), copy your API key, connect your accounts.</p>

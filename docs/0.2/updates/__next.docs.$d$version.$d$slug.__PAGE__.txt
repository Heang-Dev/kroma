32:T26f1,<p>Kroma keeps itself up to date. New versions download in the background while you work, and you choose when to restart. Your project is saved and opens again after the restart.</p>
<h2 id="how-it-works"><a class="anchor" href="#how-it-works" aria-hidden="true">#</a>How it works</h2><ol>
<li><strong>Kroma checks for a new version.</strong> The first check happens about 8 seconds after Kroma starts, then every 4 hours while it&#39;s open. New versions come from <a href="https://github.com/Heang-Dev/kroma/releases" target="_blank" rel="noreferrer">GitHub Releases</a>.</li>
<li><strong>It downloads in the background.</strong> A card appears in the bottom-right corner: <strong>Downloading Kroma 0.2.1</strong>, &quot;It downloads in the background and picks up where it stopped if the connection drops. Keep working.&quot;, with a progress bar, the speed and the time left (like <em>2.4 MB/s · 35 s left</em>).</li>
<li><strong>It&#39;s ready.</strong> The card changes to <strong>Kroma 0.2.1 is ready</strong>, &quot;Restart to finish updating. Your project is saved and opens again.&quot; You also get a <a href="/kroma/docs/0.2/notifications/">notification</a>. The card has two buttons:<ul>
<li><strong>Restart to update</strong>: Kroma closes, installs the new version, and opens again with your project.</li>
<li><strong>Later</strong>: tucks the card away. You can keep working as long as you like.</li>
</ul>
</li>
</ol>
<p>If Kroma is already up to date, nothing appears at all.</p>
<p>A dropped connection doesn&#39;t start the download over: Kroma picks up where it stopped, and so does a download left half done when you quit.</p>
<h2 id="the-status-bar"><a class="anchor" href="#the-status-bar" aria-hidden="true">#</a>The status bar</h2><p>The status bar along the bottom of every page shows the update on its right end:</p>
<ul>
<li><strong>Check for updates</strong>, when nothing is going on. Click it to check now. If you have the latest version, Kroma says <em>Kroma is up to date (0.2.0)</em>.</li>
<li><strong>Updating 45% · 35 s left</strong>, while it downloads with the card tucked away.</li>
<li><strong>Restart to update</strong> (green), when it&#39;s ready and you pressed <strong>Later</strong>.</li>
<li><strong>Update to 0.2.1</strong>, when automatic updates are off and a new version is out.</li>
</ul>
<p>Click any of them to bring the card back. The minimize button in the card&#39;s top-right corner (<strong>Minimize to the status bar</strong>) does the same as <strong>Later</strong>.</p>
<h2 id="update-settings"><a class="anchor" href="#update-settings" aria-hidden="true">#</a>Update settings</h2><p>Open <strong>Settings → About</strong>. The <strong>Updates</strong> card has:</p>
<div class="table-wrap"><table>
<thead>
<tr>
<th>Setting</th>
<th>What it does</th>
</tr>
</thead>
<tbody><tr>
<td><strong>Check for updates</strong> · <strong>Check now</strong></td>
<td>Looks for a new version right away. The line under it tells you what happened, for example &quot;You have the latest version (0.2.0).&quot; or &quot;Downloading Kroma 0.2.1 · 45%&quot;.</td>
</tr>
<tr>
<td><strong>Update automatically</strong></td>
<td>On by default: new versions download in the background. Off: Kroma only tells you a new version is out, and downloads nothing until you ask.</td>
</tr>
<tr>
<td><strong>What&#39;s new</strong> · <strong>Changelog</strong></td>
<td>Opens the list of changes on the Kroma website.</td>
</tr>
</tbody></table></div>
<h3 id="when-update-automatically-is-off"><a class="anchor" href="#when-update-automatically-is-off" aria-hidden="true">#</a>When Update automatically is off</h3><p>Kroma still checks on start and every 4 hours. When a new version is out, the card says <strong>Kroma 0.2.1 is available</strong>, &quot;A new version of Kroma is out.&quot;, with <strong>Download</strong> and <strong>Later</strong>. Click <strong>Download</strong> to get it; the card then shows the progress and <strong>Restart to update</strong> as usual.</p>
<p><strong>Check now</strong> and <strong>Check for updates</strong> follow this setting too: with it off, they only tell you a new version is out. You choose when to download.</p>
<h2 id="how-each-system-installs"><a class="anchor" href="#how-each-system-installs" aria-hidden="true">#</a>How each system installs</h2><div class="table-wrap"><table>
<thead>
<tr>
<th>System</th>
<th>What happens when you click Restart to update</th>
</tr>
</thead>
<tbody><tr>
<td><strong>macOS</strong></td>
<td>Kroma already copied the new app out of the downloaded <code>.dmg</code>. On restart it swaps the new app into place (keeping the old one until the copy works), clears the &quot;downloaded from the internet&quot; mark, and opens it. You don&#39;t need the <code>xattr</code> command again.</td>
</tr>
<tr>
<td><strong>Windows</strong></td>
<td>The new installer runs and Kroma opens again.</td>
</tr>
<tr>
<td><strong>Linux AppImage</strong></td>
<td>The AppImage file is replaced with the new one and Kroma opens again.</td>
</tr>
<tr>
<td><strong>Linux .deb</strong></td>
<td>Installing a <code>.deb</code> needs your password, so Kroma can&#39;t do it alone. It downloads the new <code>.deb</code> and opens it in your system&#39;s software installer. Install it there, then open Kroma again.</td>
</tr>
</tbody></table></div>
<p>On <strong>Windows</strong> and with the <strong>AppImage</strong>, if you simply quit Kroma after an update has downloaded, it installs when Kroma closes. On a <strong>Mac</strong>, the new version is only put in place when you click <strong>Restart to update</strong>.</p>
<h3 id="on-a-mac"><a class="anchor" href="#on-a-mac" aria-hidden="true">#</a>On a Mac</h3><p>Since 0.1.12, updates on the Mac are more careful:</p>
<ul>
<li><strong>One download at a time.</strong> Checking again while a download is running doesn&#39;t start a second download of the same file.</li>
<li><strong>A damaged download is caught.</strong> Kroma checks the downloaded file against the one on GitHub, and downloads it again instead of installing a broken copy.</li>
<li><strong>A downloaded update survives a restart.</strong> If you quit Kroma before pressing <strong>Restart to update</strong>, the update is ready straight away next time, without downloading it again.</li>
<li><strong>If it can&#39;t be installed, Kroma says why.</strong> When your Mac doesn&#39;t let Kroma replace itself in Applications, Kroma opens again on the old version, shows <em>The update couldn&#39;t be installed</em> with the reason, and opens the new Kroma Studio in Finder so you can drag it into <strong>Applications</strong>. You can also allow Kroma Studio in <strong>System Settings → Privacy &amp; Security → App Management</strong>, then update again.</li>
</ul>
<h2 id="if-an-update-doesn-t-work"><a class="anchor" href="#if-an-update-doesn-t-work" aria-hidden="true">#</a>If an update doesn&#39;t work</h2><div class="table-wrap"><table>
<thead>
<tr>
<th>Message</th>
<th>What it means</th>
</tr>
</thead>
<tbody><tr>
<td>&quot;Couldn&#39;t reach GitHub to check for updates.&quot;</td>
<td>No internet, or GitHub is blocked. Kroma tries again in 4 hours, or click <strong>Check now</strong> later.</td>
</tr>
<tr>
<td>&quot;No releases found yet.&quot;</td>
<td>GitHub had nothing to offer. Try again later.</td>
</tr>
<tr>
<td>&quot;The download was damaged. It will download again on the next check.&quot;</td>
<td>The file didn&#39;t match GitHub&#39;s. Kroma gets it again by itself.</td>
</tr>
<tr>
<td>&quot;macOS didn&#39;t let Kroma replace itself (…). Allow Kroma Studio in System Settings → Privacy &amp; Security → App Management, then update again, or drag the new Kroma Studio from the Finder window into Applications.&quot;</td>
<td>Mac only. Do one of the two, as above.</td>
</tr>
<tr>
<td>&quot;Kroma can&#39;t replace itself in …. Drag the new Kroma Studio from the window that opened into Applications.&quot;</td>
<td>Mac only. Kroma isn&#39;t allowed to write to the folder it runs from, for example when you opened it straight from the <code>.dmg</code>. A Finder window opens with the new app: drag it into <strong>Applications</strong>. From then on, run Kroma from Applications.</td>
</tr>
<tr>
<td>&quot;The downloaded update is missing. Check for updates again.&quot;</td>
<td>Mac only. The downloaded copy was removed. Click <strong>Check now</strong> in Settings → About.</td>
</tr>
</tbody></table></div>
<p>When a restart fails, a <strong>Couldn&#39;t update</strong> message appears in the bottom-right corner with the reason. You can always <a href="https://github.com/Heang-Dev/kroma/releases/latest" target="_blank" rel="noreferrer">download the latest version by hand</a> and install it over the old one, as in <a href="/kroma/docs/0.2/installation/">Installation</a>. Your projects, settings and keys are kept.</p>
<h2 id="older-versions"><a class="anchor" href="#older-versions" aria-hidden="true">#</a>Older versions</h2><ul>
<li>Versions before <strong>0.1.1</strong> can&#39;t update themselves. Download the latest once by hand.</li>
<li>On Windows and Linux, automatic updates work from <strong>0.1.2</strong>. If you have 0.1.1 on Windows or Linux, download the latest once by hand too.</li>
<li>Everything else updates to 0.2 by itself. See the <a href="/kroma/docs/0.2/upgrade/">Upgrade guide</a>.</li>
</ul>
<h2 id="staying-on-an-older-version"><a class="anchor" href="#staying-on-an-older-version" aria-hidden="true">#</a>Staying on an older version</h2><p>Turn off <strong>Update automatically</strong>, and don&#39;t click <strong>Download</strong> on the card. To read the docs for your version, use the version menu at the top of the docs sidebar. Each version&#39;s <a href="/kroma/docs/0.2/release-notes/">release notes</a> list what changed, and the <a href="/kroma/docs/0.2/upgrade/">Upgrade guide</a> explains anything you need to do when moving to a new version.</p>

# Kroma Studio

**Turn any video into a Khmer video.** Download from YouTube, Bilibili, Douyin and 1,000+ sites, get the subtitles, translate them to Khmer, give every character their own voice, and post to YouTube, Facebook and TikTok, all in one desktop app.

**Website:** https://heang-dev.github.io/kroma/

## Download

Get the latest version from [Releases](https://github.com/Heang-Dev/kroma/releases/latest):

| System | File |
|---|---|
| macOS (Apple silicon) | `Kroma-Studio-<version>-arm64.dmg` |
| Windows 10/11 (x64) | `Kroma-Studio-Setup-<version>.exe` |
| Linux (x64) | `.AppImage` (any distro) or `.deb` (Ubuntu, Debian) |

The installers aren't code-signed yet:

- **macOS:** if it says the app is damaged or won't open, run `xattr -cr "/Applications/Kroma Studio.app"` once in Terminal.
- **Windows:** on "Windows protected your PC", click **More info → Run anyway**.
- **Linux:** `chmod +x Kroma-Studio-*.AppImage`, then run it.

## Use it responsibly

Only download, translate and repost videos you have the right to use, and only clone voices that are your own or that you have the speaker's permission for.
